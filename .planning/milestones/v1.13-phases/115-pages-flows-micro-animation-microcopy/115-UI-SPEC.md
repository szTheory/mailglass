# Phase 115 — UI Design Contract

> Visual and interaction contract for Pages/Flows + Micro-Animation + Microcopy.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Nature of this phase:** a **delta pass**, not a redesign. Every primitive, form, shell,
> data-display, and component-group surface is already locked (phases 110–114; IA-LD/COPY-LD/MOTION-LD
> from phases 100–102). This contract therefore **inherits** the project's tokenized design system
> verbatim from `brandbook/tokens.css` and `mailglass_admin/assets/css/app.css`, and adds **only**
> the four new contracts this phase introduces: (1) origin-aware overlay motion, (2) theme-switch
> suppression, (3) the 320px responsive floor, (4) the new permission/stale/tenant microcopy.
> Stack is Phoenix LiveView + daisyUI 5 + Tailwind v4 standalone binary — **zero Node, zero client
> JS hooks, no pixel-diff**. shadcn/registry sections are not applicable.

## Spacing Scale

Inherited verbatim from `brandbook/tokens.css` `--mg-space-*` (all multiples of 4). Do **not** introduce new spacing values in this phase.

| Token | Value | Usage |
|-------|-------|-------|
| `--mg-space-xs` | 4px | Icon gaps, inline padding |
| `--mg-space-sm` | 8px | Compact element spacing (header flex-wrap cluster gap) |
| `--mg-space-md` | 16px | Default element spacing |
| `--mg-space-lg` | 24px | Section / card padding |
| `--mg-space-xl` | 40px | Layout gaps |
| `--mg-space-2xl` | 64px | Page-level / major section breaks |

**Touch-target floor (inherited, re-asserted at 320px this phase):** rows/inputs/buttons ≥ `--size-control-md` (44px); primary actions `--size-control-lg` (52px); compact tab strips `--size-control-sm` (36px).

Exceptions: none new. The only spacing change this phase makes is the **header flex-wrap cluster** at 320px (tenant-chip + theme-picker + nav-pills wrap using existing `--mg-space-sm` gap) — no new token, no new layout system (D-04).

## Typography

Inherited verbatim from `brandbook/tokens.css` `--mg-text-*`. Display = Inter Tight; UI/body = Inter; code/mono ID cells = IBM Plex Mono. Body line-height 1.5, headings ~1.2 (brand book). Do **not** add new sizes or weights.

| Role | Token | Size | Font | Line Height |
|------|-------|------|------|-------------|
| Display | `--mg-text-display` | 44px | Inter Tight | ~1.1 |
| H1 (single per surface) | `--mg-text-h1` | 36px | Inter Tight | ~1.2 |
| H2 | `--mg-text-h2` | 30px | Inter Tight | ~1.2 |
| H3 | `--mg-text-h3` | 24px | Inter | ~1.3 |
| Body | `--mg-text-body` | 16px | Inter | 1.5 |
| Small / label | `--mg-text-small` | 14px | Inter | 1.5 |
| Code / mono ID cell | `--mg-text-code` | 14px | IBM Plex Mono | 1.5 |

**Single-`h1` invariant (FLOW asserted):** each of the three surfaces (Operator, Inbound, Preview) must render **exactly one `h1`** across all 5 paths × 320px × system — this is a hard `flows.spec.js` assertion. Orientation-strip headings must remain `h2`/`h3` (avoids the v1.7 heading-ambiguity Playwright strict-mode trap noted in project memory).

**Mono ID cells at 320px:** `mono` ID/tenant cells use `min-w-0 truncate` + a native `title` attribute (full value on hover), never wrap or overflow.

## Color

Inherited verbatim — no value changes this phase. All `--color-*` resolve to `--mg-color-*` brand tokens (Ink / Glass / Ice / Mist / Paper / Slate). **No glassmorphism, bevels, or literal-glass visuals.**

| Role | Token | Value (light) | Usage |
|------|-------|---------------|-------|
| Dominant (60%) | `--color-base-100` → `--mg-color-background` | Paper `#F8FBFD` | Page background, primary surface |
| Secondary (30%) | `--color-base-200`/`-300` | White `#FFFFFF` / Mist-edge `#C7DCE5` | Cards, raised surfaces, borders, nav, master-detail panels |
| Accent (10%) | `--color-primary`/`--color-accent` → `--mg-color-accent` | Glass `#277B96` | See reserved-for list below |
| Destructive | `--color-error` → `--mg-color-error-solid` | Crimson `#B42318` (light) / `#E29089` (dark) | Error/failed state copy + icon only |

**Accent (Glass) reserved for:** the single obvious **primary operator action per surface**, `aria-current` active nav indicator, focus rings, selected master-detail row, and primary links — **never** applied to all interactive chrome. State layers (`:hover`/`:focus`) are the only elements that animate color (see Motion).

**Semantic data-state colors (inherited from `data_state/1`, asserted-not-introduced):**

| `data_state` kind | Role token | Used by this phase |
|---|---|---|
| `:error` / load-error | `--color-error` (Crimson) | Deliveries/inbound error copy fix (D-11) |
| `:empty` | muted (`--mg-color-text-muted` Slate) | Empty-state taxonomy (inherited) |
| `:permission_denied` | warning/neutral per existing gallery entry | **Render-only** specimen (D-05) — assert `data-state-*` testid + icon + color, no live trigger |
| `:stale` | warning (`--mg-color-warning-solid` Amber) | **Render-only** specimen (D-05) — illustrative `{HH:MM}`, no live trigger |

Theme parity: 1 happy + 1 overlay path × {light, dark, system} × 320px must pass `assertTextContrastAA` (WCAG AA contrast spot-check, D-03c).

## Motion Contract (FLOW-03 — new this phase, within MOTION-LD-01..14 locks)

All motion is `transform`/`opacity` only (color allowed at fast token on state layers), ease-OUT enter/exit, ≤300ms, reduced-motion snaps. Tokens inherited from `app.css` (`--duration-*`, `--ease-*`). This phase adds **two** new motion rules and **no new animated property**.

### M1 — Origin-aware overlays (D-07)

| Aspect | Contract |
|---|---|
| Mechanism | `.motion-overlay` gains `transform-origin: var(--mg-origin, center)`; re-parameterizes the existing `scale(0.98→1)` keyframe — **no new animated property** (MOTION-LD-04/10 compliant) |
| Origin declaration | Trigger sets a **fixed author-time keyword** inline in HEEx: `style="--mg-origin: top right"` — **never computed**, no `getBoundingClientRect`, no `phx-hook` (zero-hook lock) |
| Origin by surface role | header-anchored overlay = `top` (or `top right`); **centered confirm modals** (`operator/replay_modal.ex`, `inbound/replay_modal.ex`, both `mx-auto max-w-2xl`) keep default **`center`** (omit the var); toast = `top right` |
| Reduced-motion | already neutralized by the existing `@media (prefers-reduced-motion: reduce)` block — no extra rule needed for the origin var |

### M2 — Theme-switch never animates (D-08)

| Aspect | Contract |
|---|---|
| Mechanism | **Inverted default** — bulk theme-driven color/border transitions are **OFF by default**; only **state layers** (`:hover`/`:focus`) opt into `transition-colors` at the fast token (≤100ms, MOTION-LD-06) |
| Concrete change | Remove the always-on `transition-colors` from the theme-picker label (`components.ex` ~337); never declare `transition-colors` on `data-theme`-driven root chrome |
| Why CSS-only | the LiveView theme swap re-renders the root subtree server-side, so the next-themes "inject `*{transition:none}` + force reflow" JS trick is unavailable; inverting the default is the pure-CSS flash-free equivalent |

### Motion duration tokens (inherited, for reference)

| Token | Value | Use |
|---|---|---|
| `--duration-instant` | 90ms | focus-ring color, press feedback |
| `--duration-fast` | 150ms | row/tab state hover, modal/flash exits |
| `--duration-reveal` | 220ms | detail-pane reveal, modal enter, timeline item |
| `--duration-flash` | 200ms | toast enter |

### Overlay interaction contract (D-03b, asserted in `flows.spec.js`)

Operator + inbound replay modal × 320px must satisfy: **panel-above-scrim** (`assertPanelAboveScrim` / `elementFromPoint` hit-test + Phase-109 z-tokens), **Escape closes**, background `scrollY` unchanged (scroll-chaining guard via `overscroll-behavior: contain` on the modal scroll container).

## Responsive Contract (FLOW-02 — 320px floor)

| Aspect | Contract |
|---|---|
| New floor | **320px** (v1.11 stopped at 390; this phase lowers it in the tests it touches) |
| Boundary lock | 115 may lower 390→320 in touched `structural.spec.js` tests and patch overflow, but **must NOT promote the 320 cell into the permanent ratchet baseline** — that is Phase 116 (D-04) |
| 320 patches (no new layout system) | header flex-wrap cluster (tenant-chip + theme-picker + nav-pills); `mono` ID cells `min-w-0 truncate` + `title`; `overscroll-behavior: contain` on modal scroll; modal-above-scrim via Phase-109 z-tokens; ≥44px targets re-asserted at 320 |
| Overflow invariant | `scrollWidth − clientWidth ≤ 1` on root **and** master-detail container, all 5 paths × 3 surfaces |
| Assertions only | `getComputedStyle`, `boundingBox`, `elementFromPoint`, `data-theme` attr, `getAnimations()` — **never `toHaveScreenshot`** (no pixel-diff, ever) |

## Copywriting Contract

All new copy extends the locked **COPY-LD-07** cause-naming pattern (`[Noun] [past-tense verb]: [specific cause]` or names the recovery), the thoughtful-maintainer voice, and the seven domain nouns. Verbatim strings below are **locked — drop in as-is** (CONTEXT D-10/D-11).

| Element / state | Heading | Sub-copy | Recovery |
|---|---|---|---|
| Permission denied (deliveries) | `Access restricted` | `You do not have access to this tenant's mail operations. Ask an administrator to grant access.` | none — points to a human; **no existence leak** (byte-identical whether or not the resource exists; never names the permission or tenant) |
| Permission denied (inbound) | `Access restricted` | `You do not have access to this tenant's inbound routing. Ask an administrator to grant access.` | none |
| Stale (deliveries) | `Data may be out of date` | `Showing Deliveries as of {HH:MM}. Refresh to load the latest.` | `Refresh` (shape locked; illustrative `{HH:MM}` only — live trigger deferred to Phase 116 per D-05) |
| Stale (inbound) | `Data may be out of date` | `Showing InboundMessages as of {HH:MM}. Refresh to load the latest.` | `Refresh` |
| No-tenant (none exist) | `No tenants available` | `This operator does not have a tenant with mail activity yet. Send a Message with a tenant_id, or check the host tenant scope.` | informational |
| Sole-tenant (auto-selected) | *(no picker rendered)* | optional chip: `Scoped to {tenant}` | — (picker testid must be **absent** — proves auto-select) |
| Tenant switcher (≥2) | `Select a tenant` | `Choose a tenant to inspect its Deliveries and inbound routing. Tenant scope stays in the URL so refreshes and shared links keep the same view.` | per-tenant `Select tenant` links (list, never free-text) |
| Deliveries load error (fix D-11) | `Delivery data unavailable` | `Delivery data could not be loaded. Refresh the page or adjust the filters, then try again.` | refresh / adjust filters |

**Primary CTA per surface (the single obvious top action — FLOW-01):** Operator = `Replay delivery`; Inbound = `Replay inbound message`; Preview = `Render scenario`. Each must survive 320px in all three themes as the one visually-dominant accent action.

**Three tenant failure modes must stay lexically distinct** (D-06): no tenant chosen ≠ no access ≠ no tenants exist — each gets its own template + testid.

### Banned-language gates (D-12)

| Gate | Scope | Rule |
|---|---|---|
| VOICE-GATE (new, `check-conformance.sh`) | **`*.ex` only** | Ban "Oops"/"Whoops"/"Uh oh"/"Something went wrong" class. `.ex`-only scope sidesteps the `phoenix.mjs` inlined-"noops" false-positive |
| Domain-noun rules | rendered HTML | Enforced as **positive** render assertions in `voice_test.exs`, **never a ban grep** — `Status` is a legitimate `<th>` header (`deliveries_list.ex` ~106); a standalone `Email`/`Status`/`Notification` ban goes permanently false-red |
| Voice test (extend `voice_test.exs`) | rendered HTML | Force each new state (`:permission_denied`/`:stale`; tenant 0/1/≥2); assert `@banned_words` loop over `strip_scripts(html)` **and** the locked verbatim strings present; sole-tenant asserts picker testid **absent** |
