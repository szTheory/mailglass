## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie -> root layout | Non-auth preference data affects first paint. |
| theme return URL -> redirect | A theme-setting HTTP seam may redirect back to the current admin path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-06 | Spoofing | theme cookie | accept | Cookie controls only visual theme, never auth, tenant authority, or data scope. |
| T-112-07 | Tampering | theme cookie parsing | mitigate | Allowlist `light`/`dark`; treat all other values as system nil. |
| T-112-08 | Elevation of Privilege | return path for theme persistence | mitigate | Redirect only to same-origin mounted admin paths or sanitized relative paths; never trust external URLs. |
| T-112-SC | Tampering | package installs | accept | No package-manager install tasks exist in this plan. |
</threat_model>
