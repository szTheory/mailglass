## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tiny inline separators, compact icon/text pairs |
| sm | 8px | Compact element spacing, nav item gaps, button/icon gaps |
| md | 16px | Default element spacing, form/control spacing, card padding floor |
| lg | 24px | Section padding, page subregion gaps |
| xl | 32px | Layout gaps, major panel rhythm |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing only |

Exceptions: no one-off spacing exceptions. Control-size tokens are allowed because they are multiples of 4 and already exist: `--size-control-sm: 36px`, `--size-control-md: 44px`, `--size-control-lg: 52px`. Interactive controls default to the 44px floor; any dense-control exception is out of Phase 109 and must be GAP-recorded later, not introduced here.

Phase 109 contract: extend existing spacing gates instead of inventing a second scale. Off-grid spacing literals and arbitrary padding/margin values in admin HEEx are violations unless they are replaced with semantic tokens or documented Tailwind scale values already admitted by the gate.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 700 | 1.5 |
| Heading | 20px | 700 | 1.2 |
| Display | 28px | 700 | 1.2 |

Only weights 400 and 700 are permitted. `font-medium` and `font-semibold` remain banned because the loaded font files do not provide 500/600. Raw Tailwind type utilities (`text-xs`, `text-sm`, `text-base`, and Phase 109 additions `text-xl`, `text-2xl`, `text-3xl`) are violations; use `text-label`, `text-body`, `text-heading`, or `text-display`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Light: Paper `#F8FBFD` via `--color-base-100`; Dark: Ink `#0D1B2A` via `--color-base-100` | Page background and primary app surfaces |
| Secondary (30%) | Light: White `#FFFFFF` / Mist-edge `#C7DCE5` via `--color-base-200/300`; Dark: Ink-raised `#152538` / Ink-edge `#315069` via `--color-base-200/300` | Cards, sidebar, nav, borders, structural containers |
| Accent (10%) | Light: Glass `#277B96`; Dark/System-dark: Ice `#A6EAF2` via `--color-primary` / `--color-accent` | Primary CTA, current nav/tab state, visible focus ring only |
| Destructive | Light: Crimson `#B42318`; Dark: Crimson-bright `#E29089` via `--color-error` | Replay confirmation and destructive/error states only |

Accent reserved for: `.btn-primary`, `[aria-current="page"]`, `[aria-selected="true"]`, and `:focus-visible`. Accent is not a general hover color, decorative fill, card border, or empty-state highlight.

Phase 109 contract: color literals remain legal only inside the two daisyUI theme blocks and brandbook token comments already present in `app.css`. Admin HEEx must consume semantic color utilities or CSS variables; new raw hex values are a gate failure.

## Foundation Token Contracts

### Z-Index Layers

Target semantic stack:

| Token | Value | Usage |
|-------|-------|-------|
| `--z-base` | `0` | Default admin content layer |
| `--z-sticky` | `10` | Sticky shell/header affordances only |
| `--z-dropdown` | `20` | Menus, popovers, combobox/dropdown panels |
| `--z-overlay-scrim` | `30` | Modal/drawer scrim/backdrop |
| `--z-overlay-panel` | `40` | Modal/drawer panel; must hit-test above scrim |
| `--z-toast` | `50` | Flash/toast region |

Existing `--z-overlay` / `--z-modal` values may be migrated or retained as compatibility aliases, but new HEEx must consume the named layer tokens above. Raw `z-40`, `z-50`, or `z-[...]` classes in `mailglass_admin/lib` are violations after this phase.

Overlay interaction contract: replay modal scrims use the scrim layer and panels use the panel layer. The panel must be the top `elementFromPoint` hit-test target at its centroid in light, dark, and system.

### Focus Ring

Define one reusable focus-ring contract and use it everywhere:

| Token/Utility | Value |
|---------------|-------|
| Ring width | `2px` minimum |
| Ring offset | `2px` where an offset does not clip; inset is allowed only where offset would be clipped by the component boundary |
| Ring color | `--color-primary` (Glass in light, Ice in dark/system-dark) |
| Timing | `--duration-instant` (`90ms`) |

Raw copied strings such as `focus-visible:ring-2 focus-visible:ring-primary` and divergent `focus:outline...` idioms are violations after consolidation. The visible focus ring must meet WCAG 2.2 focus appearance expectations and non-text contrast against every surface it can sit on.

### Overlay, Motion, Elevation

Use existing motion and elevation tokens:

| Contract | Required Token |
|----------|----------------|
| Default flat surfaces | `shadow-flat` or border-only |
| Raised surfaces | `shadow-raised` |
| Modal/popover panel | `shadow-overlay` |
| Entrance motion | `--duration-reveal` + `--ease-out` + transform/opacity only |
| Focus/press feedback | `--duration-instant` |
| Row/tab hover | `--duration-fast` |
| Reduced motion | global `prefers-reduced-motion: reduce` collapse remains active |

If an overlay scrim background needs a named token, derive it from semantic daisyUI color variables, not raw hex. The current `bg-base-content/40` behavior becomes a named overlay-scrim utility or variable during Phase 109.

## Interaction Contracts

| Interaction | Contract |
|-------------|----------|
| Replay modal | Scrim below panel, panel hit-testable, `role="dialog"`, `aria-modal="true"`, Escape closes, focus remains visible. Focus-return-to-trigger can be asserted if touched but full overlay behavior work is later phase territory. |
| Toast/flash | Toast layer uses `--z-toast`; flash must not overlap primary controls in structural tests if placement is touched. |
| System theme proof | With `theme=system` or no explicit theme, root layout emits no explicit theme value and Playwright `emulateMedia({ colorScheme })` proves light/dark resolution. |
| Host isolation | Admin mount root gets a scoped stacking context (`isolation: isolate`). No global CSS, host theme mutation, or host asset pipeline dependency. |
| Touch target floor | Existing 44px floor remains the project rule. Phase 109 does not create dense-control exceptions. |

## Gate Contracts

Phase 109 gates are additive to the current lane and must prove green on current code before any token baseline update.

| Gate | Required Delta |
|------|----------------|
| Z-INDEX-GATE | Add grep block to `mailglass_admin/scripts/check-conformance.sh`; fail on literal `z-*` in `mailglass_admin/lib` after migration to layer tokens. |
| FOCUS-RING-GATE | Add grep block to ban raw focus-ring string copies and divergent outline idioms once the shared utility/token exists. |
| TYPE-GATE | Extend existing pattern to catch `text-xl`, `text-2xl`, and `text-3xl` raw size utilities. |
| SPACING/GAP-GATE | Keep multiples-of-4 discipline; extend only where needed to prevent new off-grid padding/margin/space utilities. |
| SCOPE/isolation gate | Assert admin mount/root stacking isolation and no host-global theme/style leakage. |
| Ratchet schema v3 | Add `system` to the theme axis in `ratchet_baseline_test.exs`; bump JSON schema to 3; seed `system` cells in both `prior` and `current` by copying existing light/dark scores. This is not a pillar re-score. |
| Structural WCAG 2.2 | Extend `structural.spec.js` for system theme, focus-not-obscured / focus appearance, target-size coverage, and modal panel-above-scrim hit-testing. Reuse existing computed-style and Playwright patterns. |

Do not add `@axe-core/playwright` in Phase 109. The axe JSON baseline and the new npm devDependency are Phase 116.
