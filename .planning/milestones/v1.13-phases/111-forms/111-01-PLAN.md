<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> LiveView form DOM | Untrusted form values render back into labels/help/error/control attributes. |
| Component API -> shared HTML output | Surface-specific wrappers will rely on one primitive implementation for safe form semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-111-01 | Tampering | `filter_field/1` control attributes | mitigate | Derive default IDs/names from Phoenix form field metadata and escape rendered values through HEEx. |
| T-111-02 | Information Disclosure | form error/help copy | mitigate | Error copy is generic and recovery-oriented; do not echo tenant data, recipient values, message bodies, or raw payloads. |
| T-111-03 | Spoofing | disabled/read-only states | mitigate | Real disabled, native readonly where supported, and display-only non-text read-only output are tested as distinct states. |
| T-111-SC | Tampering | package installs | mitigate | No package-manager install task exists in this plan; run existing repo-local Mix and Playwright tooling only. |
</threat_model>
