<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Adopter `Plug.Conn` session -> LiveView session callbacks | Data crosses from app-owned session state into library-owned LiveView state |
| Router macro opts -> generated route/auth behavior | Public API options shape security-sensitive mount behavior |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Information Disclosure | session callbacks | mitigate | Keep explicit preview/operator whitelist callbacks and reject whole-session passthrough. |
| T-23-02 | Elevation of Privilege | shared `live_session` | mitigate | Split preview and operator `live_session` boundaries so production operator auth does not rely on preview-only wiring. |
| T-23-03 | Tampering | macro opts | mitigate | Validate operator opts with `NimbleOptions` and avoid arbitrary auth/session maps. |
| T-23-04 | Regression | preview routes | mitigate | Preserve preview route expansion and session behavior with explicit tests. |
</threat_model>
