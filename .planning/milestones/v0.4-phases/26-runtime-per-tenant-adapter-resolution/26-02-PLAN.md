<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller opts -> outbound adapter selection | Untrusted runtime opts can override or influence provider routing |
| Tenant callback -> enqueue-time route snapshot | App-owned route policy becomes durable async intent |
| Persisted delivery row -> worker dispatch | Stored route identity controls which adapter path executes later |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-05 | Tampering | per-call override handling | mitigate | Keep override precedence explicit and reject queued raw adapter overrides that cannot be persisted safely, rather than silently dropping or serializing secrets. |
| T-26-06 | Integrity | async retry routing | mitigate | Persist `adapter_ref` at enqueue time and make worker dispatch use that stored identity instead of rerunning tenant routing per D-26-09 through D-26-15. |
| T-26-07 | Information Disclosure | queued persistence and args | mitigate | Persist only the stable ref identity on the delivery row and keep Oban args limited to `delivery_id` plus `mailglass_tenant_id`; never persist raw adapter opts or secrets per D-26-11 and D-26-14. |
| T-26-08 | Regression | default path | mitigate | Preserve the current global default path when the callback returns `:default` or is absent, and pin that behavior in sync/async/batch tests per D-26-05. |
</threat_model>
