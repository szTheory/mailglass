<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params / LiveView events → operator UI state | Operator-controlled params cross into render and query orchestration |
| Operator UI → backend query modules | UI-selected delivery ids and filters cross into tenant-scoped backend reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-05 | Information Disclosure | operator route / LiveView | mitigate | Route and LiveView must consume only tenant-scoped backend query APIs from Plan 22-01 rather than constructing raw queries inline. |
| T-22-06 | Tampering | selected delivery param | mitigate | Treat selected delivery as input to tenant-scoped backend reads; missing or unauthorized rows should render empty/error state instead of leaking data. |
| T-22-07 | Elevation of Privilege | operator UI controls | mitigate | Keep the surface read-only in this phase; do not add replay or suppression mutation controls before later-phase auth gates exist. |
| T-22-08 | Spoofing / UX ambiguity | selected row state | mitigate | Expose selected state semantically and in URL params so navigation state is explicit, not only color-based. |
</threat_model>
