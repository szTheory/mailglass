<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator interaction -> LiveView event handler | User-triggered replay clicks cross into privileged server-side action handling |
| LiveView handler -> core replay command | UI state delegates to a tenant-scoped write path that mutates durable audit state |
| Replay audit rows -> operator timeline rendering | Security-sensitive outcomes become visible to operators inside the detail pane |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-09 | Elevation of Privilege | LiveView replay handler | mitigate | Re-check `:destructive_action` at confirm time and do not trust mount-time auth alone. |
| T-24-10 | Spoofing | target selection UX | mitigate | Resolve exact replay targets server-side and require explicit operator choice when more than one candidate exists. |
| T-24-11 | Information Disclosure | result rendering | mitigate | Surface outcome and audit context without exposing raw payloads or unrelated tenant data. |
| T-24-12 | Integrity | success messaging | mitigate | Render explicit unavailable/no-op/failure states so the UI never implies downstream changes that did not happen. |
</threat_model>
