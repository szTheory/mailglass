Close v2.9 audit debt item 3, the code half: the advisory Demo Browser Evidence red at `demo.spec.js:130` / `:245` ("Received: 373", run 40210111685).

The diagnosis is in 173.1-RESEARCH.md "Item 3 Diagnosis in Detail". The orchestrator's font/geometry hypothesis is refuted: the tree is byte-identical between the passing PR head and the failing main push, and the Chromium and font versions match. The real cause is a spec race. The preview iframe's id is `"preview-iframe-" <> render_nonce`, and `PreviewLive` mints a fresh `render_nonce` on both the dead render and the connected mount. When the socket joins, the iframe is replaced at the server's 375px, which discards the spec's `iframe.style.width = "320px"`. The research reproduced this in the CI image (2 of 4 runs measured 373) and fixed it with a connected-wait (8 of 8 passed).

The fix is spec-only. The email renders correctly at 320px, and the `:245` assertion is correct and protects the 320px promise (UIQ-02 evidence), so it stays as it is.

Output: the `gotoPreview` helper applied at every `/dev/mail` navigation that is followed by an iframe mutation, repeat-run proof, a backlog todo for the product-side reload flicker, and flaky-visibility in the retained evidence checkpoint. The "green on main" half of item 3 is plans 03 and 04.

Why the checkpoint change belongs here: Playwright runs with `retries: 1` under `CI` (compose sets `CI=true` in `demo_e2e`), so a test that hits the race once and passes on retry leaves the job green. In the evidence lane the CLI `--reporter=json` override replaces the config reporters, so the job log contains no flaky marker at all, and `playwright-report.json` is deliberately NOT uploaded (`check-demo-browser-evidence.test.cjs` asserts "raw browser output cannot be uploaded"). Plan 03 must prove zero retried-then-passed tests per attempt from a non-log source, so the derived counts go into the already-uploaded `retained/checkpoint.json`. This keeps the upload contract and the lane's pass/fail semantics unchanged (planner discretion: recording, not enforcing, is the smallest reversible change that makes flakiness observable).
