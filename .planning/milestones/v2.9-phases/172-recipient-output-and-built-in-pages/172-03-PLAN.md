<threat_model>
**Security policy:** OWASP ASVS Level 1; blocking threshold: high.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted URL token → GET controller | Token verification determines valid, expired or invalid page without exposing token/delivery data. |
| Delivery recipient → HEEx response | A valid recipient may contain markup and must stay escaped; failure states must receive no recipient data. |
| Browser GET → durable unsubscribe state | GET is read-only; only protocol POST owns the event/suppression transition. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-172-05 | Tampering | Recipient value in built-in HTML | high | mitigate | Task 1 uses HEEx interpolation and hostile recipient assertions for HTML escaping. |
| T-172-06 | Information Disclosure | Invalid/expired token responses | high | mitigate | Task 2 passes fixed state only and tests responses contain no token, recipient or delivery identifier. |
| T-172-07 | Elevation of Privilege | GET versus POST unsubscribe state | high | mitigate | Tasks 1–2 assert GET no-write and preserve POST canonical event/suppression/idempotency tests. |
| T-172-08 | Spoofing | Browser page completion claim | medium | mitigate | Tasks 1–2 state the actual GET result and only supported next steps with distinct 404/410 recovery. |
| T-172-SC | Tampering | Dependency supply chain | high | mitigate | No package installation is planned; if execution introduces one, first require a package legitimacy audit and a blocking review for assumed or suspicious packages. |
</threat_model>
