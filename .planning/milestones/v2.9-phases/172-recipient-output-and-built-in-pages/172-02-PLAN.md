| Boundary | Description |
|----------|-------------|
| Author-provided HTML/HEEx → generated plaintext | Losing or duplicating a destination can mislead a text-only recipient about the action. |
| Logical HTML → CSS inliner / final wire | Internal markers and conditional markup must not leak or corrupt final HTML. |

| T-172-04 | Information Disclosure | Renderer text and HTML output | medium | mitigate | Task 2 preserves the existing marker-strip and skip stages and tests that hidden preheader/internal data do not leak into generated text or final HTML. |
