## Trust Boundaries
| Boundary | Description |
|---|---|
| Modal client events to server review | Client-selected ID and queued Confirm events are untrusted. |
| Server review to host destructive-action callback | Existing host policy and recent auth must be checked at action time. |
| Stored replay audit to operator UI | Audit metadata and failure reasons are not a blanket display allowlist. |
