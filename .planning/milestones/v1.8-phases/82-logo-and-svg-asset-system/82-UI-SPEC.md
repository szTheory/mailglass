# Phase 82 - UI Design Contract

> Visual and interaction contract for the Logo and SVG Asset System phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope Lock

Phase 82 is a source-native brandbook asset phase, not a product UI phase.

In scope:

- `brandbook/logo-options.md` or an equivalent durable logo-option review artifact.
- Lightweight editable SVG option sketches under `brandbook/assets/options/` if needed for visual comparison.
- Final SVG assets under `brandbook/assets/`: primary lockup, icon-only mark, monochrome mark, favicon, and social avatar.
- Logo-specific status and usage wording in `brandbook/index.html`, `brandbook/brand-book.md`, and `brandbook/README.md`.

Out of scope:

- Root README, Hex.pm, HexDocs, landing copy, launch copy, social copy blocks, and specimen work.
- Product/admin implementation code, public APIs, release workflow, package allowlists, validation scripts, PDFs, raster exports, font binaries, vendor design files, and broad trademark/legal/name strategy.

Primary visual goal: preserve "Mailglass makes email visible" through a wordmark-first logo system and a small-size-safe source-native mark. The active reset prioritizes email-source primitives over pane/card geometry.

## Logo Direction Contract

The review artifact must compare multiple credible directions before final asset approval. The original A/B/C pane set and D/E/F wordmark-header set remain rejected evidence; the active review set is G-R.

| Direction | Visual Idea | Required Disposition |
|-----------|-------------|----------------------|
| A-F - rejected prior evidence | Pane/card drafts and wordmark/header variations. | Preserve as rejected evidence only unless the maintainer explicitly overrides the reset. |
| G-L - email-source family | Header checksum, console row, inline source cursor, at lens, header stack, and source diff. | Active priority family selected by the maintainer. Prefer the primitive that feels most ownable at 16px/32px and beside the wordmark. |
| M-R - inspection/infrastructure outliers | Protocol brackets, routing node, delivery timeline, normalized event pulse, caliper, and refraction line. | Active contrast set to avoid another narrow variant round. Accept only if it remains source-native and avoids generic devtool or send-arrow readings. |

Forbidden visual logic: paper planes, mailbox-on-post imagery, chat bubbles, send arrows, glossy app-icon treatment, mascots, bevels, glassmorphism, decorative gradients, blobs, and unnecessary path complexity.

Final posture:

- Wordmark-first. The primary lockup is the main logo.
- Mark-secondary. Use the mark for favicon, avatar, compact badges, and small surfaces.
- Small-size simplicity beats detail. If ambiguity remains, simplify the primitive rather than adding ornament.
- Glass is a metaphor, not a visual excuse. Keep marks flat, restrained, and border-first where a boundary is needed.

## Typography

Use exactly these phase-level text roles for review artifacts and brandbook copy touched by this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 400 | 1.5 |
| Body | 16px | 400 | 1.5 |
| Heading | 24px | 700 | 1.2 |
| Display | 40px | 700 | 1.2 |

Typography rules:

- Weights are limited to 400 and 700.
- Letter spacing is `0`.
- Use sentence case for prose and labels.
- The primary logo lockup may keep live SVG text sized to its asset viewBox. Treat that sizing as logo artwork geometry, not a reusable UI type token.
- Do not add font binaries or outlined wordmark exports in this phase unless a future distribution surface proves the need.

## Color

Use the brandbook tokens as source values. The final assets should feel flat, crisp, and inspectable.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Paper `#F8FBFD` on light surfaces; Ink `#0D1B2A` on dark/reversed surfaces. | Backgrounds, primary logo fill, readable asset surfaces. |
| Secondary (30%) | Mist `#EAF6FB`, Slate `#5C6B7A`, border `#C7DCE5`. | Quiet panes, message-line secondary strokes, captions, review structure, subtle asset backgrounds. |
| Accent (10%) | Glass `#277B96`; Ice `#A6EAF2` only on dark/reversed surfaces. | Primary mark line, selected option indicator, active logo-section link, focus ring, dark-surface mark border/highlight. |
| Destructive | Crimson `#B42318`. | Only for explicit warnings about rejected/banned constructs or invalid SVG safety findings. |

Accent reserved for: primary mark message line, selected/final direction indicator, active logo-section navigation state, focus ring, and dark/reversed surface highlight. Never use Glass for all borders, all links, all icons, or decorative fills.

State color rule: if warning/error/success language appears in the review artifact, pair color with explicit text or labels. Never rely on color alone.

## Asset Construction Contract

| Asset | Required Construction |
|-------|-----------------------|
| `logo-primary.svg` | Editable SVG with live wordmark text, `role="img"`, `viewBox`, unique `title`/`desc` IDs, and matching `aria-labelledby`. |
| `logo-mark.svg` | Shape-only icon mark with simple pane/message geometry, accessible metadata, and unique IDs. |
| `logo-monochrome.svg` | Shape-only mark using `currentColor` where practical, accessible metadata, and unique IDs. |
| `favicon.svg` | Small-size-safe mark, reviewed at 16px and 32px, accessible metadata, and unique IDs. |
| `social-avatar.svg` | Dark/reversed avatar using final mark, transparent-background-friendly mark construction where appropriate, accessible metadata, and unique IDs. |
| Option SVGs | Lightweight, source-control-friendly, clearly labeled as options/drafts, and safe for local inspection. |

Unique ID defaults:

| Asset | Title ID | Description ID |
|-------|----------|----------------|
| `logo-primary.svg` | `mg-logo-primary-title` | `mg-logo-primary-desc` |
| `logo-mark.svg` | `mg-logo-mark-title` | `mg-logo-mark-desc` |
| `logo-monochrome.svg` | `mg-logo-monochrome-title` | `mg-logo-monochrome-desc` |
| `favicon.svg` | `mg-favicon-title` | `mg-favicon-desc` |
| `social-avatar.svg` | `mg-social-avatar-title` | `mg-social-avatar-desc` |

SVG safety bans:

- No raster images.
- No embedded fonts.
- No scripts.
- No `foreignObject`.
- No `data:` or base64 payloads.
- No external `http://` or `https://` references.
- No dynamic behavior or vendor-export clutter.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Approve logo system |
| Empty state heading | Logo options are not drafted yet |
| Empty state body | Add source-native SVG directions before selecting the final Mailglass mark. |
| Error state | Logo asset check failed. Review the flagged SVG metadata, safety, or small-size issue, then update the affected brandbook asset. |
| Destructive confirmation | No user-facing destructive action in this phase. Replacing draft SVG assets is source editing, not a destructive UI flow. |

Additional copy rules:

- Keep language exact, calm, and maintainer-oriented.
- Prefer "selected direction", "final refinement", "small-size review", "unique SVG IDs", and "visible email".
- Avoid "final brand launch", "logo pack", "export kit", "magic", "glossy", "mascot", "paper plane", and "send arrow" as positive descriptors.
- When brandbook wording changes from draft to approved, be specific: Phase 82 approves the logo/SVG asset system only. Do not imply Phase 83 copy/specimens or Phase 84 validation proof are complete.
