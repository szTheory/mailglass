    generate a throwaway Phoenix app for the installer smoke). Connect, or run mix ci.fast for the offline

<threat_model>
## Trust Boundaries

No new trust boundary is introduced. This phase changes developer/CI tooling only: Mix alias
lists, two local preflight probe scripts, a Makefile, and contributor docs. No untrusted input
crosses into the system, no network endpoint is exposed, no package is installed, and no product
code path (transport/route/webhook) changes (D-23). The preflight scripts only read env vars and
make outbound reachability probes to localhost Postgres and hex.pm.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-128-01 | Tampering | mix ci alias body drifting from the required CI gates | medium | mitigate | Plan 02 adds the MIXCI-03 parity-drift test (shared ci_lanes source) that fails loudly if a required/advisory lane leaves the alias union |
| T-128-02 | Denial of Service | preflight scripts hang on an unreachable host/network probe | low | mitigate | Both probes use bounded timeouts (pg_isready / curl --max-time / bash /dev/tcp subshell timeout) so they fail fast, never block |
| T-128-03 | Information Disclosure | raw DBConnection / connection stacktrace leaking host/credentials on failure | low | mitigate | preflight guards intercept before the DB task runs and print a single sanitized brand-voice line naming only host:port, never a stacktrace (MIXCI-04) |
</threat_model>
