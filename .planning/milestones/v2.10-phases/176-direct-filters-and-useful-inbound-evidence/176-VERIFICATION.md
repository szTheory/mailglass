## Gap Closure Evidence

Operator.Mount installs a handle_params hook in the shared operator live_session used by Deliveries and Inbound. It compares the exact incoming tenant_id key with the previously authorized key. Same-Account filter, page and selection patches continue without a second auth call; a changed, missing or blank key calls the adopter's existing operator_access callback before either LiveView's reads. A successful grant keeps existing actor/assign normalization; a denial halts with the existing redirect and flash behavior.

The connected authorization tests prove both sides of that boundary. For each surface an allowed patch first produces an observed repository query; a subsequent denied patch redirects and produces none. Additional cases cover activity-free host-approved Accounts, callback context, normalized success forms, absent/blank values, custom/default denial behavior, and unchanged filter/page/selection callback counts.
