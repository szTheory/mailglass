## Telemetry Foundation (TELE)

- [x] **TELE-01**: Inbound emits ingress request spans with PII-free metadata.
- [x] **TELE-02**: Inbound emits route-match spans with candidate and outcome metadata.
- [x] **TELE-03**: Inbound emits mailbox execution spans for fresh and replay execution paths.
- [x] **TELE-04**: Inbound emits persistence spans for insert/update/dedup behavior.
- [x] **TELE-05**: Raising telemetry handlers do not break business logic.
- [x] **TELE-06**: Inbound telemetry metadata passes the extended `NoPIIInTelemetry` proof surface.
- [x] **TELE-07**: Inbound telemetry is surfaced through `MailglassAdmin.PubSub.Topics`.
- [x] **TELE-08**: A StreamData property proves 1000-replay convergence on inbound ingest.

## Shared MIME Module (MIME)

- [x] **MIME-01**: `MailglassInbound.MIME` parses canonical RFC 5322 payloads into a stable internal representation.
- [x] **MIME-02**: MIME backend access is gated through `Mailglass.OptionalDeps.GenSmtp`.
- [x] **MIME-03**: `mix mailglass.inbound.doctor` reports MIME backend availability.
- [x] **MIME-04**: Malformed MIME returns structured inbound MIME errors without raising.

## Mailgun Inbound Ingress (MGUN)

- [x] **MGUN-01**: Mailgun inbound verifies HMAC signatures and rejects forged requests via `SignatureError`.
- [x] **MGUN-02**: Mailgun ingress reuses replay-cache semantics to prevent timestamp replay.
- [x] **MGUN-03**: Mailgun ingress normalizes payloads into canonical inbound records and persists raw evidence.
- [x] **MGUN-04**: The inbound allowlist recognizes the Mailgun provider key.
- [x] **MGUN-05**: Mailgun setup guidance ships as a first-party walkthrough.

## SES Inbound Ingress (SESI)

- [x] **SESI-01**: SES inbound verifies SNS X.509 signatures using the trusted cache/policy path.
- [x] **SESI-02**: SES ingress auto-confirms trusted `SubscriptionConfirmation` notifications.
- [x] **SESI-03**: `MailglassInbound.S3Fetcher` defines the S3 retrieval contract for `Action: S3`.
- [x] **SESI-04**: Fake and real `ExAwsS3` adapters ship behind the optional-deps gateway.
