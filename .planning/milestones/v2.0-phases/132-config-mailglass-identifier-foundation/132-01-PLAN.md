<objective>
Establish the core additive schema-config foundation for v2.0 (Design Phase A): a shared
`Mailglass.Identifier` validator, a `:schema` config key on `Mailglass.Config` with a
boot-validated `:persistent_term`-cached `schema/0` accessor, and a one-line delegate
refactor of the migration-layer identifier check onto the shared validator.

Purpose: everything downstream (Phase 133 facade, Phase 134 migrations) reads
`Config.schema/0` and validates through `Mailglass.Identifier`. This plan makes that
value correct, O(1) on the hot path, and fail-fast at boot — with ZERO runtime behavior
change (the facade is not wired here).

Output: `Mailglass.Identifier` module + `validate!/2`; `Mailglass.Config` `:schema` key,
`schema/0`, `warm_schema/0`, boot-warm `:persistent_term.put`; migration delegate;
unit tests for the validator and the config accessor.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adopter config → `Mailglass.Identifier.validate!/2` | The `:schema` config value (adopter-controlled) crosses into a validator that is the chokepoint before any later DDL/query builder (Phase 133+/134) interpolates the schema name into SQL. No SQL interpolation happens in THIS phase (facade unwired). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-132-01 | Tampering | `:schema` config value reaching a future DDL/query builder | high | mitigate | Fail-fast `Mailglass.Identifier.validate!/2` at the config boundary: regex `\A[a-zA-Z_][a-zA-Z0-9_]*\z` rejects quotes/semicolons/whitespace/dashes; 63-byte NAMEDATALEN guard rejects truncation-aliasing names. Validated once at the cache-write boundary; the string is frozen in `:persistent_term`. This phase is the SQL-injection-prevention chokepoint for the schema name. |
| T-132-02 | Denial of Service | over-63-byte identifier silently truncated by Postgres → schema aliasing | medium | mitigate | D-10 63-byte guard raises `%Mailglass.ConfigError{type: :invalid}` before any name reaches Postgres. |
| T-132-03 | Tampering | migration-path identifier check drifting from the config-path check | medium | mitigate | D-11 collapses `Migrations.Postgres.validate_identifier!/2` to a delegate on the same shared validator — one regex, one contract, no drift. |
</threat_model>
