# Milestone v1.2: Inbound Production Confidence

**Status:** ✅ SHIPPED 2026-05-26
**Phases:** 44.5, 45-50, 50.5, 50.7, 51
**Total Plans:** 42

## Overview

v1.2 took `mailglass_inbound` from the narrow v1.1 opening slice to a
production-credible inbound surface. The milestone added telemetry and replay
proof, Mailgun and SES ingress, Hex-public testing helpers and generators,
tenant-safe inbound admin workflows, operator runtime tooling, and six
adopter-facing guides. It also closed the remaining v1.0 carry-forward debt in
Phase 51 so the project exits the milestone with the inbound expansion shipped
and the old stability-closeout backlog retired.

The live release shipped on 2026-05-26 as `mailglass` 1.2.0,
`mailglass_admin` 1.2.0, and `mailglass_inbound` 0.2.0.

## Milestone Summary

**Decimal Phases:**

- Phase 44.5: linked the v1.2 implementation milestone to the live `v1.0` and
  `v1.1` Hex publish ceremony.
- Phase 50.5: linked the product milestone to the live `v1.2` release.
- Phase 50.7: inserted a post-release bookkeeping pass before the final
  stability closeout.

**Key Decisions:**

- Finish the inbound package by lift-and-alias from already-proven outbound
  patterns instead of inventing a second architecture.
- Keep inbound production support narrow and operator-first: telemetry, replay,
  admin evidence, runtime tools, and docs before broader adjacent bets.
- Preserve the release-cadence rule: implementation does not outrun live Hex
  publishes anymore.
- Close the old v1.0 carry-forward debt in the same milestone instead of
  letting it compound into the next planning cycle.

**Issues Resolved:**

- Inbound now has full telemetry, idempotency proof, major-provider ingress,
  testing helpers, generators, admin observability, runtime tooling, and docs.
- The v1.0 closeout debt is no longer open: branch protection, citext race,
  boundary warnings, WR ledger, and Phase 35 bookkeeping all reconciled.
- The live release is shipped and verified from a clean sandbox install.

**Issues Deferred:**

- `SEED-003-ecosystem-integrations` remains acknowledged but intentionally
  dormant for a future milestone.
- v1.3 candidates remain deferred until a fresh milestone is opened:
  Cloudflare Email Routing, `gen_smtp` relay ingress, Conductor-style synthetic
  inbound UI, and inbound auto-suppression experimentation.

**Technical Debt Incurred:**

- Release-workflow fanout still depends on the documented manual
  `workflow_dispatch` fallback because GitHub's `GITHUB_TOKEN` anti-recursion
  blocks downstream publish workflows from release-please-created releases.
- Admin publish still needs an explicit Hex index wait on inbound when the two
  sibling packages release in parallel.
- A few latent hardening ideas remain documented in per-phase review artifacts,
  but none are active milestone blockers.
