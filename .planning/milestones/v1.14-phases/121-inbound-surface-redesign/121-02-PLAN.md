<objective>
Harden the Inbound evidence-card raw-payload reveal affordance to a true ARIA disclosure with a re-redact
collapse + a screen-reader announcement, and add a PII-free reveal-audit telemetry count — WITHOUT weakening
any redacted-by-default invariant (D-10 hard guardrail). Concretely (D-11):

- Make the reveal button (`evidence_card.ex:42-49`, testid `inbound-evidence-reveal`) a true ARIA disclosure:
  `aria-expanded={@reveal_state == :revealed}`, `aria-controls="inbound-evidence-raw"`, keep `type="button"`,
  `min-h-11`, `mg-focus-ring`; add the secondary line "Contains unredacted PII." Keep the reveal label "Reveal
  raw source".
- Add a "Re-redact raw source" collapse control in the `:revealed` branch routing back to `:redacted` via ONE
  new `handle_event("re_redact_raw", ...)` — NO fourth state atom — returning focus to the reveal button.
- Add an `aria-live="polite" role="status"` text region (planner's placement call within evidence_card.ex)
  announcing "Raw source revealed. This payload contains unredacted PII." on grant / "Raw source re-redacted."
  on collapse — never the warning border color alone (WCAG 1.4.1). Keep the denied/redacted copy verbatim.

And (D-12): emit `[:mailglass_admin, :inbound, :reveal_raw, :stop]` with metadata `tenant_id` / `record_id` /
`outcome ∈ :granted | :denied` ONLY — never payload/body/headers/recipient (CLAUDE.md telemetry PII rule).
mailglass_admin has NO telemetry today, so this is a single fire-and-forget :telemetry.execute/3, not a full
span. Durable persisted reveal-audit is DEFERRED (Phase 123+).

Hard guardrails (D-10 — do NOT weaken): reveal_state defaults :redacted and re-sets to :redacted on every
selection (assign_inbound_state/3 :565) and clear (clear_surface_state/1 :584); the EvidenceCard render must
NOT be hoisted outside the per-selection reset; the locked boundary (structural.spec.js:1176-1177 — redacted
visible + raw count 0 on first selection) must NOT be weakened (that e2e change is owned by Plan 04, but this
plan must keep the render shape compatible with it). inbound-evidence-raw renders ONLY in :revealed.

Purpose: Bring the PII-reveal affordance to WCAG 2.2 AA + APG (disclosure semantics, text-announced state,
re-redact path) and make reveals observable via telemetry, without touching the capability gate, the storage
contract, or the redacted-by-default boundary.

Output: ARIA-disclosure reveal + re-redact + aria-live in evidence_card.ex; re_redact_raw handler + PII-free
telemetry in inbound_live.ex; co-located component tests. Reuses existing classes (btn btn-ghost min-h-11
px-md, text-body, text-secondary) — D-18, no new Tailwind utility, no mix assets.build.
</objective>
