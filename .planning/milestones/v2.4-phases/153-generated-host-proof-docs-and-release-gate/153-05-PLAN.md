<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/CI → preflight | A caller asks the library to inspect database, configuration, and running queue state. |
| public HTTP → operator router | Untrusted requests approach operational mail data and controls. |
| host config → Mailglass | Host-owned secrets, Repo, maintenance, and authentication settings cross the package boundary. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-153-17 | Information Disclosure | Preflight output | high | mitigate | Return check names and remediation while redacting secret/config values in implementation and tests. |
| T-153-18 | Spoofing | Production operator mount | high | mitigate | Require and exercise the host authentication plug before the admin router per D-16. |
| T-153-19 | Tampering | Migration-currentness check | high | mitigate | Query the configured Repo through the public migration-version API and fail closed on inaccessible or stale state. |

| T-153-SC | Tampering | Package installs | high | mitigate | No new npm, pip, or cargo package install is permitted by this plan. |
</threat_model>
