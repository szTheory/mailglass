<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| committed transaction → host lifecycle | Mailglass invokes adopter code that may fail, exit, or return an invalid Multi. |
| committed transaction → PubSub | Bounded domain facts leave durable storage for process-local observers. |
| request workers → shared PostgreSQL identities | Concurrent connections race on unique event/suppression identities. |
| configured schema/tenant → ambient database state | Hostile search_path and decoy rows attempt cross-schema or cross-tenant influence. |
| suppression store → outbound adapter | Preflight must block before recipient data crosses to the provider boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-152-05 | Denial of Service | lifecycle callback and returned Multi | high | mitigate | Execute only after commit in a separate best-effort transaction; log/ignore failure without changing empty 200 per D-11/D-12. |
| T-152-06 | Information Disclosure | lifecycle/broadcast payload | high | mitigate | Whitelist bounded domain facts and exclude token/private message content per D-14. |
| T-152-07 | Repudiation / Tampering | replay and concurrent race effects | high | mitigate | Gate callback and broadcast on the transaction's `created` classification and assert one emission under a true race per D-13/D-19. |
| T-152-08 | Tampering / Information Disclosure | search_path and tenant decoys | high | mitigate | Explicit prefix options, tenant-restored operations, hostile-path decoys, and cross-tenant negative controls per D-02/D-15/D-16. |
| T-152-09 | Elevation / Information Disclosure | suppression-to-Outbound boundary | high | mitigate | Real preflight matrix proves only matching tenant/address/stream is blocked before adapter invocation per D-09/D-10. |

</threat_model>
