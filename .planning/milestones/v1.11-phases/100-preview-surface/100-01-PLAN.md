<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL -&gt; PreviewLive assigns | Untrusted `theme`, `width`, `mailable`, and `scenario` params cross into LiveView state. |
| Browser URL -&gt; root layout | Untrusted query string influences root `data-theme`. |
| PreviewLive -&gt; Sidebar links | URL state is re-emitted into relative scenario links. |
| PreviewLive -&gt; iframe/pane | Previewed Message HTML remains isolated from admin chrome. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-100-01 | Tampering | `PreviewLive.handle_params/3` theme parsing | mitigate | Whitelist only `dark`, `mailglass-dark`, `light`, and `mailglass-light`; invalid/absent theme maps to `nil`, not arbitrary attributes. |
| T-100-02 | Denial of Service | mailable/scenario params | mitigate | Preserve `String.to_existing_atom/1` in `safe_mailable_atom/1` and `safe_scenario_atom/1`; do not create atoms from params. |
| T-100-03 | Information Disclosure | `/dev/mail` route scope | mitigate | Per D-01, do not add a sibling LiveView, production `/ops` route, public API, auth path, or core email component change. |
| T-100-04 | Tampering | Preview iframe/pane | mitigate | Keep the existing iframe sandbox contract in `Tabs`; frame theme marker may affect pane chrome only and must not loosen sandbox permissions. |
| T-100-05 | Repudiation | root/page theme behavior | mitigate | Add ExUnit assertions for index and scenario routes so explicit theme behavior is recorded in automated test output. |
| T-100-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install or new dependency is planned; use existing Phoenix, LiveView, Tailwind, and Playwright stack only. |
</threat_model>
