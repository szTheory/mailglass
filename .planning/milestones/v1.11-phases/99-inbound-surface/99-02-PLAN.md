## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -&gt; InboundLive filters | Operator-controlled URL params and form fields affect tenant-scoped reads and UI state. |
| InboundLive -&gt; optional gateway | Summary/list/detail/timeline loads cross the optional inbound package boundary. |
| InboundLive -&gt; rendered HTML | Tenant data, counts, and empty states are rendered to the browser. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99-06 | Information Disclosure | overview rendering | mitigate | Overview reads only tenant-scoped `summary/2` counts; no addresses, subjects, headers, or raw payload fields are rendered in overview. |
| T-99-06A | Denial of Service | `load_inbound_summary/1` optional gateway absence | mitigate | Return the exact zero summary when `gateway_available?/0` is false before any `apply(@gateway, :summary, ...)`; LiveView coverage exercises `/ops/mail/inbound?tenant_id=...` in that no-optional runtime degradation path. |
| T-99-07 | Spoofing | mobile back and URL state | mitigate | Mobile back only clears `inbound_id` through existing `build_path/4`; no new route or unauthenticated state transition is introduced. |
| T-99-08 | Tampering | filter params | mitigate | Keep existing `normalize_filter_params/1`, closed outcome allow-list, positive window parsing, and URL state push_patch pattern. |
| T-99-09 | Denial of Service | repeated filter patches | accept | Existing LiveView synchronous read path remains bounded to summary/list/detail calls; no async polling or new broadcast source is introduced. |
| T-99-10 | Information Disclosure | empty/detail error copy | mitigate | Detail-error copy names tenant/filter mismatch without revealing whether a foreign record id exists. |
| T-99-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install or new dependency is planned. |
</threat_model>
