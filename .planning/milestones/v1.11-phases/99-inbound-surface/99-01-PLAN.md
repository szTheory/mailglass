<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LiveView filters -&gt; inbound summary read model | Operator-supplied tenant/provider/search/window filters cross into SQL-backed aggregate reads. |
| mailglass_admin -&gt; optional mailglass_inbound | Admin package must compile and degrade safely when the optional inbound package is absent. |
| inbound summary -&gt; database | Aggregate counts must not widen beyond the active tenant. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99-01 | Information Disclosure | `Summary.summarize/2` | mitigate | Require nonblank `tenant_id`, add explicit `record.tenant_id == ^tenant_id`, apply `Tenancy.scope(tenant_id)`, and test tenant A never counts tenant B rows. |
| T-99-02 | Tampering | `search` filter | mitigate | Reuse the `Records.escape_like/1` style so `%`, `_`, and `\\` are escaped and search remains parameter-bound. |
| T-99-03 | Denial of Service | aggregate summary query | mitigate | Keep the summary narrow to count aggregates over tenant/window/search/provider filters; reject blank tenant with zero summary; use positive `window_hours` default. |
| T-99-04 | Information Disclosure | overview denominator | mitigate | Do not apply selected outcome filter to summary denominator; tests prove the overview cannot mislead by using capped or outcome-filtered list rows. |
| T-99-05 | Elevation of Privilege | admin optional dependency gateway | mitigate | Expose only a read-only `summary/2` wrapper through existing conditionally compiled gateway; no new public route, API, or action. |
| T-99-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install or new dependency is planned. |
</threat_model>
