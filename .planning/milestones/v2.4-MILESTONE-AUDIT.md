connections. The principal chain is:

   Event, private Payload, and an ID-only Oban job.

   provider boundary, classifies honest outcomes, and scrubs bounded payloads.
4. Phase 152 atomically converges one-click events and stream suppressions; the
   shared Phase 149 preflight blocks the next matching send.
5. Phase 153 proves those public paths in a production-shaped generated host and
   binds protected publication to exact public artifacts.
