## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow dispatcher → protected release | A user allowed to dispatch workflows is not automatically allowed to exercise admin merge or release authority. |
| GitHub collaborator-permission API → authorization output | Zero-exit bytes remain untrusted until exact JSON role and permission fields are validated. |
| authorization output → PAT-bearing steps | The privileged secret must remain unreachable unless the authorization decision is true. |
