## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser or mailbox-provider request -> controller | Untrusted token-bearing GET/POST requests hit a core controller |
| Controller -> event ledger transaction | Durable unsubscribe state and adopter lifecycle work execute inside one database transaction |
| Transaction -> PubSub broadcast | Transient observability events must not leak ahead of durable commit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-07 | Repudiation | unsubscribe POST | mitigate | Append an `:unsubscribed` event through `Events.append_multi/3` instead of toggling mutable flags |
| T-11-08 | Denial of Service | controller flow | mitigate | Keep POST narrow, idempotent, and transaction-bounded; lifecycle receives the multi and must not force pre-commit external HTTP calls |
| T-11-09 | Elevation of Privilege | GET rendering | mitigate | Render a library-owned standalone page or redirect escape hatch; never couple to adopter layouts or session assigns |
</threat_model>
