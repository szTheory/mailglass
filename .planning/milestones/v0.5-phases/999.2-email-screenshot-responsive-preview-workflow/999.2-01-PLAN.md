<threat_model>
## STRIDE Threat Register

| Category | Threat | Surface | Mitigation in this plan | Verification hook |
|---|---|---|---|---|
| Spoofing | Crafted URL params attempt invalid atom/state injection | `PreviewLive` query parsing | Parse via allowlists and safe conversion only (`to_existing_atom` + explicit width/theme guards) | `preview_live_test.exs` invalid-param tests + no crash path |
| Tampering | Capture state differs between runs due implicit UI-only toggles | Scenario/device/theme state | Canonical URL as source of truth; helper modules derive deterministic entries from explicit params | repeated matrix-order test in `capture_matrix_test.exs` |
| Repudiation | Maintainer cannot reproduce which state was captured | Matrix entry model | Include canonical URL + matrix coordinates per entry for replayability | `rg` checks for URL/width/theme/scenario fields in matrix module/tests |
| Information Disclosure | Future capture flow accidentally includes raw/header surfaces with sensitive values | Capture scope contract | Wave 1 matrix contract is HTML preview-state only; no raw/header artifact contract added | matrix test asserts tab/surface metadata stays scoped |
| Denial of Service | Auto-scan discovery explosion creates unusable matrix cardinality | Discovery + matrix build | Encode explicit skip metadata and deterministic filtering to keep behavior bounded and diagnosable | matrix tests for skip handling on `:no_previews` / `{:error, _}` |
| Elevation of Privilege | Work introduces new core runtime API claims | `lib/mailglass` boundary | Restrict file touch list to `mailglass_admin` preview modules/tests only | final no-core-touch check via file list and `git diff --name-only` during execution |
</threat_model>
