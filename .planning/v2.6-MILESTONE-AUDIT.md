## Critical Requirement Gaps

### QUAL-03 — deterministic required proof must block merges truthfully

The integration checker ran the actual local parity path. `mix ci` reached the root full-suite stage and failed at `test/mailglass/adapters/swoosh_test.exs:274`: the test attaches a process handler to the global `[:mailglass, :outbound, :dispatch, :stop]` telemetry event and asserts no event arrives, but the async full suite can emit that event from another test. The isolated Swoosh suite passed five consecutive runs, demonstrating order/concurrency dependence rather than stable proof.

### QUAL-09 — flaky/order-dependent tests must be governed or made deterministic

The failing assertion is not an explicit skip, flaky tag, or registered sleep site, so the current exception governor does not inventory it. A required suite can therefore fail nondeterministically without the ownership/reason/expiry contract promised by QUAL-09.
