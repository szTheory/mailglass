# Quick Task 260618-1qj: De-hardcode the reference-app trust baseline

## Objective

Eliminate the "coordinated 5-file hand-edit" friction behind thread
`release-pipeline-maintenance.md` item 2. The reference-app trust baseline required
manual edits on every release because two places hardcoded exact sibling versions:
- `scripts/check_clean_baseline_hex_only.sh` → `required = [{"mailglass", :hex, "1.4.5"}, ...]`
- `test/mailglass/publish/ci_trust_lane_contract_test.exs` → `1.4.5`/`1.1.5` literals in fixtures

Make the maintenance version-agnostic so future dep/version bumps need no baseline babysitting.

## Decision: de-couple maintenance from versions (keep the property that matters)

The baseline guard's real job is "siblings resolve from `:hex` (a real published consumer),
never a `path:`/`git:` dep." The exact-version assertion was the entire maintenance burden and
adds little (the committed `mix.lock` is already the reproducible pin). Drop the version literal;
keep the Hex-source check.

## Tasks

1. **Guard version-agnostic** (`check_clean_baseline_hex_only.sh`): assert each sibling resolves
   via `:hex` with a well-formed (non-empty) version string; drop the hardcoded version list.
   - verify: `bash scripts/check_clean_baseline_hex_only.sh reference/host_app/mix.lock` → exit 0,
     "Hex-first OK" ×3. ✓
2. **Contract test version-agnostic** (`ci_trust_lane_contract_test.exs`): version-agnostic regexes;
   repurpose the "rejects stale version" test → "rejects a non-Hex (path/git) source" (the property
   still enforced). Keep malformed/security/non-tuple tests.
   - verify: `mix test .../ci_trust_lane_contract_test.exs` → 5/5. ✓
3. **Widen pins** (`reference/{host_app,demo_app}/mix.exs`): `~> 1.4`/`~> 1.1` → `~> 1.0` (floor is
   cosmetic; mix.lock pins the real version) so they never need editing.
4. **Refresh both locks** to current published: 1.4.5/1.4.5/1.1.5 → 1.7.0/1.7.0/1.4.0 via
   `mix deps.update mailglass mailglass_admin mailglass_inbound` (host_app Hex; demo_app
   `MAILGLASS_DEMO_DEPS=hex`). Surgical diffs (host 9 lines, demo 10).
   - verify: guard + contract test green against refreshed lock; `host_app` compiles clean against
     1.7.0. ✓
5. **Push; confirm both Trust Lane jobs + Advisory Matrix green on main.**

## Outcome

Future releases need ZERO baseline edits — just `mix deps.update <siblings>` to refresh the lock;
no script/test/pin changes. Closes thread item 2 (the last open maintenance item).
