```elixir
  @doc """
  Signs `svix_id.svix_timestamp.raw_body` with the given secret.
  Returns the base64-encoded HMAC-SHA256 signature.
  """
  @spec sign_resend_payload(String.t(), String.t(), binary(), binary()) :: String.t()
  def sign_resend_payload(svix_id, svix_timestamp, raw_body, secret) do
    signed_content = "#{svix_id}.#{svix_timestamp}.#{raw_body}"
    :crypto.mac(:hmac, :sha256, secret, signed_content)
    |> Base.encode64()
  end
```

  <action>
1. Create `lib/mailglass/webhook/providers/resend.ex` implementing `@behaviour Mailglass.Webhook.Provider`.
   - In `verify!(raw_body, headers, config)`:
     - Fetch `"svix-id"`, `"svix-timestamp"`, `"svix-signature"` from `headers`. If missing, `raise Mailglass.SignatureError.new(:missing_header, provider: :resend)`.
     - Enforce timestamp tolerance: If `abs(System.system_time(:second) - String.to_integer(svix_timestamp)) > Map.get(config, :timestamp_tolerance, 300)`, `raise Mailglass.SignatureError.new(:stale_timestamp, provider: :resend)`.
     - Extract secret: `config.secret` MUST begin with `"whsec_"`. Execute `let "whsec_" <> encoded_secret = Map.fetch!(config, :secret)` (adjust for Elixir matching) and `{:ok, secret_bytes} = Base.decode64(encoded_secret)`. (Missing secret triggers `ConfigError` via helper).
     - Calculate HMAC: `expected_sig = Base.encode64(:crypto.mac(:hmac, :sha256, secret_bytes, "#{svix_id}.#{svix_timestamp}.#{raw_body}"))`.
     - `svix_signature` may have multiple signatures separated by space. Split by `" "`, check if `Enum.any?` matches `"v1," <> sig` and `Plug.Crypto.secure_compare(sig, expected_sig)`. If no match, `raise Mailglass.SignatureError.new(:bad_signature, provider: :resend)`.
   - In `normalize(raw_body, headers)`:
     - `Jason.decode(raw_body)` returning `%Mailglass.Events.Event{}`.
     - Event mapping logic:
       - `"email.sent"` -> `{:sent, nil}`
       - `"email.delivered"` -> `{:delivered, nil}`
       - `"email.delivery_delayed"` -> `{:deferred, nil}`
       - `"email.bounced"` -> `{:bounced, :bounced}`
       - `"email.complained"` -> `{:complained, nil}`
       - Any other type logs warning and -> `{:unknown, nil}`
     - Metadata setting:
       - `"provider" => "resend"`
       - `"provider_event_id" => payload["id"]`
       - `"record_type" => payload["type"]`
       - `"message_id" => payload["data"]["email_id"] || to_string(payload["id"])`
2. Create `test/mailglass/webhook/providers/resend_test.exs`:
   - Write tests for successful `verify!/3`.
   - Write tests for failing `verify!/3` raising `:stale_timestamp`, `:bad_signature`, `:missing_header`.
   - Write tests verifying `normalize/2` correctly returns expected mapped taxonomy types for Resend payloads.
