<task type="auto">
  <name>Task 2: Replace Python Script in post-publish-smoke.yml</name>
  <files>.github/workflows/post-publish-smoke.yml</files>
  <action>
    Replace the inline Python script in the 'Add mailglass deps' step with an Elixir one-liner using 'elixir -e'.
    
    Current Python logic:
    - Reads 'mix.exs'
    - Injects ':mailglass' and ':mailglass_admin' with "== {version}" into the 'deps' list.
    
    New Elixir equivalent:
    ```bash
    elixir -e '
      version = System.get_env("VERSION")
      mix_path = "mix.exs"
      content = File.read!(mix_path)
      entries = "      {:mailglass, \"== #{version}\"},\n      {:mailglass_admin, \"== #{version}\"},\n"
      updated = String.replace(content, ~r/(defp deps do\n\s*\[\n)/, "\\1" <> entries, global: false)
      File.write!(mix_path, updated)
    '
    ```
    Ensure the workflow remains functional and easier to maintain without a Python dependency.
  </action>
  <verify>
    <automated>grep -F "elixir -e" .github/workflows/post-publish-smoke.yml</automated>
  </verify>
  <done>Smoke test workflow now uses native Elixir for dependency patching.</done>
</task>
