- **Title**: H1 with a clear name.
- **Intro**: Short paragraph explaining the goal.
- **Prerequisites**: H2 list of requirements (Elixir version, config needed).
- **Numbered Steps**: H2 headers like `## 1) Step name`.
- **Code Blocks**: Elixir/Bash blocks with comments indicating the file path.
- **Callouts**: `> **Title.** Message` for warnings or important tips.
- **Tables**: Used for mapping (e.g., event types, response codes).
- **Troubleshooting**: H2 section at the end with H3 for specific issues and bullet points for solutions.
