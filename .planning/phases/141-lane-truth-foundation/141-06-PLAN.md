## Decisions recorded here (never made by omission)

1. **The disposition record lives in `MAINTAINING.md` § "Required Checks" — no new `.planning/`
   register is created (D-05).** `ci_lanes.ex` already cites that section as authoritative, so honoring
   the citation is cheaper than relocating it. Both existing register precedents
   (`.planning/RATCHET-GAP-REGISTER.md`, `.planning/research/v1.14/DEFECT-REGISTER.md`) are
   milestone-scoped and would be archived away.

2. **`promote` means "recorded as the recommendation", not "executed" (D-07).** `hex_audit` and
   `deps_audit_advisory` carry `promote`; the actual promotion to merge-gating is Phase 142/VULN-03's
   work and must not happen in this phase. The table must say so in the `reason` cell so nobody reads a
   recommendation as a shipped state.

3. **`Branch Protection Advisory` is classified publish-gating even though its name says "advisory".**
   That is the D-04 rationale in miniature: the naming-convention matcher misses it (no `(` follows
   "Advisory"), so it is publish-blocking in principle today. It is moot only because its substantive
   step carries `continue-on-error: true`; Phase 144/TRUTH-02 makes it failable, at which point the
   classification goes live. Record that in the `reason` cell — Phase 141 records the disposition, it
   does not implement TRUTH-02.
