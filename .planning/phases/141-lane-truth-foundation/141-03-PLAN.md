## Decisions recorded here (never made by omission)

1. **Display name is `Design System Conformance (shell gates)`, not D-08's recommended
   `Design System Conformance (Elixir 1.18 / OTP 27)`.** RESEARCH.md F4 proved the job runs no Elixir at
   all — it is a checkout plus three greps. Every other `(Elixir 1.18 / OTP 27)` lane in `ci.yml` is
   BEAM-bearing, so that suffix would actively mislead, and ROADMAP criterion 3 asks for a name that
   tells a maintainer what ran. D-08 marked its string as "recommended" and CONTEXT.md's
   `### Claude's Discretion` permits naming adjustments. **Consequence honored:** a non-matrix job gets
   **no** runtime name suffix from GitHub (RESEARCH F1), so this exact full string is what
   `gate-ci-green` will see and what every registry must carry byte-for-byte.

2. **`credo_strict`'s display name is deliberately NOT changed.** This is what collapses D-11's
   six "atomic rename sites" to three (RESEARCH.md **F9**): `ci.yml:395`, `ci_lanes.ex:63`,
   `ci_parity_drift_test.exs:109` and `:187` all keep the same string and need no edit. **That verdict
   holds only because the display name is preserved and because plan 141-04 leaves the parity lists
   unpartitioned.** If either changes, D-11's full six-site list applies.

3. **This is a split, not a promotion.** Neither resulting job enters `ci_green.needs`. Until 141-04
   lands, `conformance_gates` is unclassified in `gate-ci-green` and therefore falls through into the
   same unrecognized-but-blocking-if-red tier `credo_strict` already occupied — exactly where its steps
   effectively already were. Posture is identical before and after this plan.

4. **The extra runner's cost is ~20-40 seconds, not D-13's 2-3 minutes.** D-13 budgeted duplicated
   OTP/Elixir setup, dependency install, and cache restore. RESEARCH.md F4 shows the new job needs none
   of them. Record the corrected figure as the SEED-006 input; quoting 2-3 min would mis-prioritize that
   milestone. D-13's *acceptance* of the cost is unchanged — only the number is corrected.
