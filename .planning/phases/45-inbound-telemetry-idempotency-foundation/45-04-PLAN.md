<objective>
Prove inbound ingest is idempotent by construction: a StreamData property that replays
an arbitrary inbound payload 1000× through the REAL persist+route+execute write path and
asserts exactly one `InboundRecord` per unique `(tenant_id, provider, provider_message_id)`
and exactly one fresh `ExecutionRun` per inserted record. This is the inbound mirror of
the shipped outbound `WebhookIdempotencyConvergenceTest`.

Purpose: TELE-08 makes idempotency a tested invariant the rest of v1.2 (Mailgun/SES
ingress, replay tooling, admin) can rely on. The dedupe anchor is the Postgres unique
index `mailglass_inbound_records_postmark_idempotency_idx` — only a real DB can prove it,
which is why Plan 01 (Wave 0) stood up `MailglassInbound.TestRepo`.
Output: the convergence property test + a CI gate to run the 1000-run property.
</objective>
