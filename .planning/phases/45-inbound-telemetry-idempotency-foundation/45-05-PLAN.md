<objective>
Close CR-01 (BLOCKER) and WR-02 (WARNING): make the two custom Credo guards actually
fire for their stated targets, and add two cheap recurrence backstops so this
"claimed-but-inert guard" defect class cannot recur silently.

- **CR-01:** `NoBareOptionalDepReference` keys `gated_modules` on the phantom alias
  `GenSmtp`, but gen_smtp is an Erlang lib reached only via the atoms `:mimemail`
  and `:gen_smtp_client`. `Map.fetch(gated_modules, :mimemail)` always misses, so a
  bare `:mimemail.decode(...)` anywhere in inbound passes `mix credo --strict`. Fix
  is config-only (the check code already resolves Erlang-atom roots): add the real
  atom keys to `.credo.exs`. Add the Erlang-atom regression test the old Oban-only
  probe never covered.

  Every inbound event is `:telemetry.span/3`, so the widened
  `required_root: [:mailglass, :mailglass_inbound]` checks nothing. Add a second
  `walk/5` clause for `:telemetry.span/3` with the `min_segments - 1` threshold
  (the runtime appends `:start`/`:stop`/`:exception`). Add fixture cases.
- **Recurrence backstops:** a check-coverage meta-test (would have caught both
  gaps — neither had a test) and a `.credo.exs` config sentinel (pins the
  load-bearing keys against config drift).
