<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| inbound pipeline → :telemetry handlers | Operator-attached handlers are untrusted code; a raising handler must not break business logic. |
| inbound persist → Phoenix.PubSub subscribers | Broadcast payload crosses to admin/other subscribers; must be PII-free and tenant-scoped. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-04 | Information Disclosure | telemetry span metadata (4 sites) | mitigate | Metadata whitelist enforced in code (D-45-03) and at lint by NoPIIInTelemetry (enabled for inbound in Plan 01); test asserts no forbidden keys present. |
| T-45-05 | Information Disclosure | PubSub broadcast payload | mitigate | Payload carries only record id + provider + record_type (no recipient/sender/body); reviewed against D-45-03. |
| T-45-06 | Information Disclosure | cross-tenant PubSub subscription | mitigate | Topic string includes tenant_id (`mailglass:inbound:<tenant>`); subscribers scope to their tenant (V4). |
| T-45-07 | Denial of Service | raising telemetry handler | mitigate | `:telemetry.span/3` isolates handler exceptions (TELE-05); test attaches a raising handler and asserts the pipeline still succeeds; no custom rescue around business code. |
| T-45-08 | Denial of Service | PubSub server unavailable at shutdown | accept | `safe_broadcast/2` rescues ArgumentError/RuntimeError + catches :exit and returns :ok; the committed row is the durable source of truth (mirror Projector). |
| T-45-09 | Tampering | literal topic string at broadcast site (LINT-06) | mitigate | Broadcast uses the `Topics.inbound_record_inserted/1` builder, never a literal; PrefixedPubSubTopics passes and the string is `mailglass:`-prefixed regardless. |
</threat_model>
