<objective>
Close WR-03 (WARNING): the CLAUDE.md-mandated `mix compile --no-optional-deps
--warnings-as-errors` lane for `mailglass_inbound` is silently absent, and the
compile actually exits 1 in the worktree.

Root cause (a real cross-package gap, NOT a toolchain artifact): under
`--no-optional-deps`, Oban is stripped from both inbound's own dep and the path-dep
core, so the core `Mailglass.Oban.TenancyMiddleware` module is elided. `worker.ex`
references it at line 36, guarded at runtime by `Code.ensure_loaded?/1`, so there is
NO runtime reference — but the static xref pass warns because inbound's
`elixirc_options` `no_warn_undefined` list (`[Oban, Oban.Job, Oban.Worker]`) is
missing the cross-package middleware module that core's own `mix.exs` list DOES
include. With `--warnings-as-errors`, the build exits 1.

Fix: add `Mailglass.Oban.TenancyMiddleware` to inbound's `no_warn_undefined`
(one identifier, mirroring core), and add a dedicated `inbound_compile_no_optional_deps`
CI job so the lane proves the fix (red→green in one CI run). Pair them so the lane
exercises the fix.

Purpose: make the optional-dep degraded-compile guarantee for inbound real and
continuously verified, not claimed-but-absent.
Output: corrected inbound `mix.exs` + new CI job.
</objective>
