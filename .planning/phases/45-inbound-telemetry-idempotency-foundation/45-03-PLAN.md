<objective>
Build the standalone `MailglassInbound.MIME` parser over `:mimemail.decode/1` (gen_smtp
1.3.0), gated through an extended `Mailglass.OptionalDeps.GenSmtp` gateway, that NEVER
raises on malformed input and returns a stable internal representation. Add the new
package-local `MailglassInbound.MIMEError` defexception (D-45-16 supersedes the
REQUIREMENTS.md MIME-04 wording, because `Mailglass.Error` is a behaviour/namespace with
no parent struct).

Purpose: Phase 46 (Mailgun/SES raw-MIME ingress) is the first consumer. This phase ships
the producer only — D-45-18 forbids wiring MIME into the working JSON-based Postmark/
SendGrid normalize paths. The never-raise contract is load-bearing: `:mimemail.decode/1`
escapes through THREE mechanisms (`erlang:error`, `throw`, and `:exit`/`:undef` from
iconv) — a rescue-only wrapper would let `bad_content_type`/`bad_disposition`/`badchar`
throws and iconv exits escape, violating MIME-04.
Output: extended gateway `decode/2` seam, `MailglassInbound.MIMEError`, `MailglassInbound.MIME`,
CHANGELOG entries, and tests proving parse + degraded fallback + never-raise across all
three escape mechanisms.
</objective>

:mimemail.decode(raw, opts) returns the 5-tuple {Type, SubType, Headers, Parameters, Body}:
  Type, SubType :: binary (e.g. <<"text">>, <<"plain">>; <<"multipart">>, <<"mixed">>)
  Headers       :: [{binary, binary}]  (proplist of decoded headers)
  Parameters    :: MAP with atom keys:
      content_type_params  => [{binary, binary}]   (e.g. [{<<"charset">>, <<"utf-8">>}, {<<"name">>, ...}])
      disposition          => binary  (<<"inline">> default | <<"attachment">>)
      disposition_params   => [{binary, binary}]   (e.g. [{<<"filename">>, <<"a.pdf">>}])
      transfer_encoding    => OPTIONAL — declared in @type but NOT set by decode; use Map.get (RESEARCH A1)
  Body :: binary (leaf) | mimetuple (message/rfc822) | [mimetuple] (multipart — RECURSE)
