## Sampling Rate

- **After every task commit:** Run quick lane (`mix mailglass.publish.check --package <pkg>` for the package whose `mix.exs` changed; `actionlint .github/workflows/<file>` for any YAML change; `mix test mailglass_admin/test/mailglass_admin/mix_config_test.exs --warnings-as-errors` for any change touching `release-please.yml` sed step).
- **After every plan wave:** Run `mix verify.stability_contract` plus all ci.yml required-bucket jobs (Support Contract Core, Support Contract Admin, Compile No Optional Deps, Format Check, Credo Strict, Dialyzer, Docs Warnings as Errors, Hex Audit, Installer Golden Gate, Operator Browser Gate).
- **Phase gate (before live publish in Wave 4):** `dry_run=true package=all` workflow_dispatch on Release PR head ref (or `rc1` tag per Pitfall 4 Option B); GITHUB_STEP_SUMMARY review for all three packages; PR diff review for manifest bumps + sibling-pin updates + curated CHANGELOG headers preserved.
- **Post-publish gate (Wave 4 + 5):** `mix hex.info <pkg> <ver>` for all three; HexDocs URLs return HTTP 200; `gh api repos/szTheory/mailglass/branches/main/protection` returns 200; 60-minute timer expired without revert (PASS) OR revert/retire executed and recorded.
- **Max feedback latency:** ≤60s for repo-truth lane; ≤10min for the full ci.yml gate; ≤2h end-to-end through dry-run dispatch.
