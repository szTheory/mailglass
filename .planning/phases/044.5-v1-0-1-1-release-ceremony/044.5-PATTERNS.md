## Shared Patterns

### Brand voice (CLAUDE.md `## Brand & Voice`)
**Source:** CLAUDE.md `## Brand & Voice` section
**Apply to:** All adopter-facing markdown — `CHANGELOG.md` 1.0.0 entry, `mailglass_admin/CHANGELOG.md` 1.0.0 entry, `mailglass_inbound/CHANGELOG.md` 0.1.0 entry, `docs/upgrade-from-0.x.md`, `MAINTAINING.md` edits, `MILESTONES.md` updates.

**Pattern:**
- Clear, exact, confident (not cocky), warm (not cute), modern (not trendy), technical (not intimidating).
- Errors composed: `Delivery blocked: <specific reason>`. Never `Oops!` or `Something went wrong`.
- Direct word: "preview" not "experience the full rendering lifecycle".
- No emojis.

### Conventional Commits + `Release-As:` footer (Pitfall 5 mitigation)
**Source:** MAINTAINING.md:136-139
**Apply to:** Commit A's commit message (recommended per RESEARCH.md Pitfall 5 lines 807-820).

**Pattern (verbatim from RESEARCH.md):**
```text
chore: prepare 1.0.0 release ceremony

Unlinks mailglass_inbound to its own 0.x version line and rewrites the
release-please.yml sync step to handle the new pin shape per D-44.5-01.

Release-As: 1.0.0
```

**Why:** Forces release-please to cut at 1.0.0 even if the bundle range lacks `feat!:` / `BREAKING CHANGE:` commits. Without this footer, release-please may compute 0.4.0 instead.

### Idempotency guard pattern
**Source:** `publish-hex.yml:177-184` (publish-core), `publish-hex.yml:263-270` (publish-admin)
**Apply to:** New `publish-inbound` job idempotency guard.

**Pattern:**
```yaml
- name: Skip if version already on Hex
  id: idempotency
  run: |
    VERSION="${{ steps.version.outputs.version }}"
    if mix hex.info <pkg> "${VERSION}" 2>/dev/null | grep -q "Released:"; then
      echo "Version ${VERSION} of <pkg> already on Hex — skipping publish (idempotency guard)."
      echo "skip=true" >> "$GITHUB_OUTPUT"
    fi
```

**Why:** Workflow safely re-runnable. If inbound publish.check fails after admin succeeds, partial-release recovery is the same `workflow_dispatch` fallback path.
