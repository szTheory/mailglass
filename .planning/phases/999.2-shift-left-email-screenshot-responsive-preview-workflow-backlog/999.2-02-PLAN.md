<threat_model>
## STRIDE Threat Register

| Category | Threat | Surface | Mitigation in this plan | Verification hook |
|---|---|---|---|---|
| Spoofing | Capture command points at an unintended host and records misleading artifacts | `--base-url` handling | Validate URL scheme/host format and default to explicit local preview host unless overridden intentionally | task tests for base-url validation + dry-run contract |
| Tampering | Artifact rows/filenames are mutated or reordered between runs | manifest/checkpoint writer | Deterministic sort and identity keys; include file hash per image entry | manifest test with repeated generation equality checks |
| Repudiation | Maintainer cannot prove what matrix was captured | checkpoint output | Checkpoint records matrix cardinality, dimensions, and command options used | checkpoint test + docs command examples |
| Information Disclosure | Artifacts accidentally include sensitive headers/raw payload content | capture scope + docs | Keep workflow scoped to preview HTML render captures and avoid raw/header artifact claims | docs text + manifest schema review in tests |
| Denial of Service | Huge matrix or bad CLI input causes long/flaky runs | task CLI + matrix sizing | Strict option parsing, dimension allowlists, and fail-fast invalid input handling | mix-task invalid-option tests |
| Elevation of Privilege | Shell-injection via Chromium invocation options | browser execution path | Use `System.cmd/3` arg list and explicit flag construction, never shell concatenation | `rg` verification for `System.cmd` invocation style |
</threat_model>
