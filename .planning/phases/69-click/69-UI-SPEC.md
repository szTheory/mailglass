## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Micro gaps for inline label/value groupings |
| sm | 8px | Compact label spacing, stat/card interior rhythm |
| md | 16px | Default card and stat padding |
| lg | 24px | Main page horizontal padding at base breakpoint |
| xl | 32px | Section separation between mast/stats/cards |
| 2xl | 48px | Major vertical section breaks |
| 3xl | 64px | Hero-to-content breathing room on wide screens |

Exceptions: 44px minimum touch target height for clickable icon-only or compact controls; dashboard cards remain larger than this minimum.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f8fbfd` | Page background and primary calm operator surface |
| Secondary (30%) | `#eaf6fb` | Stats tiles, card background tint, support panels |
| Accent (10%) | `#277b96` | Kicker labels, focus/hover emphasis, key route affordances |
| Destructive | `#0d1b2a` | Reset warning text and destructive confirmation framing |

Accent reserved for: route category kickers (`Preview`, `Outbound`, `Inbound`, `Reset`), active hover/focus outline, and explicit evidence-first callouts only.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Open outbound operator |
| Empty state heading | No demo evidence found |
| Empty state body | Run `mix demo.reset` (or dashboard reset) to reseed Northstar demo data, then open preview/operator routes again. |
| Error state | Could not load demo evidence summary. Refresh the page; if it persists, run `mix demo.reset` and retry. |
| Destructive confirmation | Reset seed data: This destructive action truncates and reseeds deterministic demo evidence tables for tenant `northstar`. |
