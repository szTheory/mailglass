<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Request-derived bucket key → public ETS | Recipient/domain/tenant values can create concurrent state and consume node memory. |
| Concurrent caller → token state | Many schedulers race to refill and decrement the same bucket. |
| Inbound package → core private engine | Shared implementation must not collapse package-specific config, ownership, or release behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-156-01 | Elevation of Privilege | atomic bucket refill/decrement | high | mitigate | Exact-tuple CAS, bounded retry, and a barrier test that asserts the exact success count after refill. |
| T-156-02 | Denial of Service | missing-key admission | high | mitigate | Owner-serialized admission, 100,000-key default cap, idle purge, and explicit fail-closed result. |
| T-156-03 | Information Disclosure | inbound limiter error/telemetry | medium | mitigate | Preserve bucket-type-only inbound context and existing telemetry allowlists in regression assertions. |
</threat_model>
