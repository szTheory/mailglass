# Phase 98 — UI Design Contract

> Visual and interaction contract for the Operator / Deliveries surface (`/ops/mail`,
> `OperatorLive` + `operator/*` components). Generated by gsd-ui-researcher, verified by
> gsd-ui-checker.
>
> **This phase is heavily pre-decided.** It IMPLEMENTS the locked v1.11 research decisions
> (`.planning/research/v1.11/SUMMARY.md`, 69 LD-IDs) and the binding CONTEXT decisions
> D-01..D-08. This contract ENCODES those locks with citations — it does NOT re-open any axis
> owned by an LD-ID or a D-0x. Every value below traces to a source; nothing here is a fresh
> design choice except where explicitly marked "Claude's Discretion" per CONTEXT.md.

## Scope

**In scope (Operator surface only):** GROUP-01, PAGE-01, PAGE-02, RESP-01, FLOW-01, FLOW-02,
A11Y-01, A11Y-02 for `/ops/mail` (`OperatorLive` + `operator/*` components). Composes the
already-uplifted Phase 97 shared components into coherent groups; corrects the master-detail
responsive grid; folds CR-01/02/03 nil-guard tech debt; extends the single seed scenario for
full-state URL reachability.

**Out of scope:** Inbound (99), Preview (100), global microcopy pass (101), global motion pass
(102). Shared components were uplifted in Phase 97 — this phase composes, it does not re-uplift.

**Stack:** Phoenix LiveView + HEEx, daisyUI 5 + Tailwind v4 standalone binary (zero Node),
vendored heroicons. shadcn is **not applicable** (no React/Next/Vite). No third-party registry.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Phoenix/HEEx — shadcn N/A) |
| Preset | not applicable |
| Component library | daisyUI 5 (vendored, standalone-binary Tailwind v4) |
| Icon library | heroicons (vendored inline via `heroicons-inline.js` `@plugin`; no heroicons dep) |
| Font | Inter (UI/body `--mg-font-ui`), Inter Tight (display `--mg-font-display`), IBM Plex Mono (`--mg-font-mono`) |
| Token source of truth | `brandbook/tokens.css` (`--mg-*`) → consumed by `mailglass_admin/assets/css/app.css` `@theme` |
| Theme switching | `data-theme="mailglass-light"` / `data-theme="mailglass-dark"` on shell root (STATE-LD-10) |

**Hard constraints (bind every element, from STATE.md v1.11 + brand book):** zero Node toolchain;
type weights **only 400/700**; flat elevation (border-first, no glassmorphism/bevels/shadows —
`shadow-overlay` permitted on the modal/overlay tier ONLY); **10%-accent rule**; semantic tokens
only (no hex literals, no raw palette, no arbitrary Tailwind values); motion ≤300ms, ease-out,
transform/opacity only, `prefers-reduced-motion` respected, CSS+LiveView.JS only (no client JS
hook); PII minimization (`mask_recipient/1`) and multi-tenant safety preserved in seed work.

## Spacing Scale

Declared values from the `@theme` token scale (source: `brandbook/tokens.css` `--mg-space-*`).
Phase composes groups on the **existing token rhythm** (D-07). No arbitrary `gap-[…]`,
`px-[…]`, or `tracking-[…]` — the token structural assertion + RATCHET-03 grep gate fail on them.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--mg-space-xs`) | Icon gaps, inline padding, badge gap |
| sm | 8px (`--mg-space-sm`) | Compact element spacing, intra-group `gap-sm`, `px-sm` (Tier-2 ghost CTA) |
| md | 16px (`--mg-space-md`) | Default element spacing, intra-group `gap-md`, `px-md` (Tier-1 CTA padding) |
| lg | 24px (`--mg-space-lg`) | **Outer group inter-spacing `gap-lg`** (D-07), section padding |
| xl | 40px (`--mg-space-xl`) | Layout gaps, major section breaks |
| 2xl | 64px (`--mg-space-2xl`) | Page-level spacing |

**Group spacing rhythm (D-07):** outer groups `gap-lg`; intra-group `gap-md`/`gap-sm`
(`operator_live.ex:281,285,397`, `shell.ex:181`). Flat elevation on every group container:
`bg-base-200 border border-base-300 rounded-box`, no shadow-overlay.

**Radius:** `rounded-box` (daisyUI, maps to `--mg-radius-lg` 12px) on cards/panes/strips.

Exceptions:
- Touch-target floor `min-h-11` (44px) on ALL interactive controls — A11Y-01 hard constraint,
  not a spacing token (height, not gap). Already met on row buttons, nav, inputs, filters.
- `replay_modal` is the ONLY element permitted `shadow-overlay` (flat-elevation exception per
  STATE-LD-17). All other operator containers are border-first, shadow-free.

## Typography

Source: `@theme` type scale from `brandbook/tokens.css` `--mg-text-*`. **Only two weights exist
(400 / 700)** — hard constraint; no faux-bold, no intermediate weights (IA-LD-04, STATE-LD-06).

| Role | Token / class | Size | Weight | Line Height | Usage |
|------|---------------|------|--------|-------------|-------|
| Body | `text-body` (`--mg-text-body`) | 16px | 400 | 1.5 | Default operator prose, card body copy |
| Label | `text-label` | 14px (`--mg-text-small`) | 700 | 1.4 | Filter/section labels (uppercase), tenant chip, metadata keys |
| Heading | `text-heading` (`--mg-text-h3`) | 24px (Phase-97 token; was banned `text-xl`) | 700 | 1.25 | Detail-header `h2`, deliveries-list card `h2` |
| Display | `text-h2` (`--mg-text-h2`) | 30px | 700 | 1.2 | Shell page `h1` (L2 surface name) |

**Banned type escapes (RATCHET-03 grep gate fails CI):** `text-lg`, `text-xl`, `text-2xl`, any
arbitrary `tracking-[…]`. Audit the WHOLE operator template and fix to token (D-03).

**Filter/section label class is LOCKED (IA-LD-04, STATE-LD-13, D-03):**
`text-label uppercase font-bold text-secondary` — the arbitrary `tracking-[0.08em]` on the
deliveries-list card `h2` (`operator_live.ex:~409`) and any filter-label spans MUST be removed;
letter-spacing is token-owned (global `h1/h2/h3` rule). Label copy unchanged (Tenant, Provider,
Status, Event, Window, Search).

## Color

Source of truth: `brandbook/tokens.css` `--mg-*`, consumed via daisyUI semantic tokens. **Use
semantic token classes only** — never hex, never raw palette. Dark resolution is owned by
DARK-LD-* (the dark `--mg-*` reassignment block; do not author dark hex inline).

| Role | Light value | Dark value | daisyUI token | Usage |
|------|-------------|------------|---------------|-------|
| Dominant (60%) | Paper #F8FBFD | Ink #0D1B2A | `bg-base-100` / `bg-base-200` | Shell background, group surfaces (DARK-LD-01) |
| Secondary (30%) | white surface / Mist | #152538 raised | `bg-base-200` + `border-base-300` | Cards, master-detail panes, support cards, orientation strip (flat, border-first) |
| Accent (10%) | Glass #277B96 | Ice #A6EAF2 | `border-primary`, `text-primary`, `badge-primary`, `ring-primary` | **See reserved-for list** (DARK-LD-04) |
| Destructive | Error #B42318 | #E29089 | `btn-error`, `badge-error`, `border-error` | Replay button, failed/bounced/rejected status badges only |

**Accent (10%) reserved for — explicit list (DARK-LD-04, STATE-LD-05/06/09/11):**
- Selected delivery row left border: `border-l-4 border-primary` (single active row) — STATE-LD-11
- Active nav indicator: `border-primary` on active `nav_link`/`nav_pill` — STATE-LD-06
- `orientation_strip` `hero-lifebuoy` icon: `text-primary` (single icon, not a fill) — STATE-LD-09
- In-flight status badges only: `:dispatched`/`:queued`/`:sent` → `badge-primary` — STATE-LD-05
- Focus ring on all interactive elements: `ring-primary` (Glass light / Ice dark) — DARK-LD-03

**Accent PROHIBITED on (DARK-LD-04):** default structural borders (use `border-base-300`), card
fills, section backgrounds, badge fills outside in-flight statuses. Borders that delineate
interactive regions in dark mode upgrade to `border-input` (#62809A) per DARK-LD-02/07 — but
that is a token-mapping handled in `app.css`, not an inline class choice here.

**Status-badge color map is LOCKED (STATE-LD-05) — all 22 atoms resolve to a non-default class:**
`badge-primary` (in-flight) · `badge-success` (delivered/opened/clicked/accepted/replay-succeeded)
· `badge-warning` (deferred/unsubscribed/no_match/reconciled) · `badge-error`
(bounced/failed/rejected/complained/failed_ingest/replay-failed) · `badge-outline`
(autoresponded/unknown/ignore/replay-requested AND phantom `:suppressed`/`nil` fallback).
Size `:sm` in list rows, `:md` in detail headers.

**Contrast (A11Y-02):** all text meets WCAG AA on its *actual* surface in both themes; non-text
(borders, focus ring) meets WCAG 1.4.11 ≥3:1. Dark border upgrade to `border-input` is mandatory
where a border is the sole elevation boundary (DARK-LD-02). Verify computed, not assumed.

## Layout / Information Architecture (IA-LD-01..07 — LOCKED)

This phase keeps BOTH operator views and brings BOTH to the locked spec (D-01):

**`:overview` view** — first-time orientation landing (satisfies PAGE-01 "orient first-time
operators"). Retained as a composition-layout realization of PAGE-01 (IA-LDs are silent on it).
Health stat cards + Navigate cards; spacing on token scale, flat elevation, 10%-accent held.
Exact card grouping rhythm is **Claude's Discretion** (CONTEXT.md) within those rules.

**`:deliveries` view** — advanced master-detail surface (PAGE-01 "advanced operators").

### Master-detail responsive grid (IA-LD-03, D-02) — replaces `lg:grid-cols-[minmax(22rem,28rem)_1fr]`

| Viewport | Grid | Behaviour |
|----------|------|-----------|
| 390px | master list 100% width | Record selection reveals detail at 100% via `:if selected_delivery != nil` in-place reveal **with a back affordance** — NOT a `push_patch` to a new route. Back affordance shape is Claude's Discretion (CONTEXT.md) provided it is the `:if`-toggled in-place reveal. |
| 768px | `grid-cols-[40%_60%]` | left = list + filters, right = detail / orientation_strip |
| 1440px | `grid-cols-[33%_67%]` | left = list + filters, right = detail |

Column widths are grid **percentage templates** (layout structure, not spacing tokens);
intra-column spacing uses token gaps (`gap-sm`/`gap-md`). Breakpoints are the 768/1440 tiers, NOT
`lg:`.

### Orientation strip placement (IA-LD-01, STATE-LD-09)
- ≥768px: renders inside the right (detail) column when `selected_delivery == nil` (replaces the
  "no record selected" blank area).
- 390px: renders below the filter form, above the record list, full-width, when no selection.
- No motion class on the strip (born token-clean).

### Filter disclosure (IA-LD-02, D-06)
- Filter controls (`FiltersForm.fields`) persist in the DOM at ALL viewports.
- ≥768px: filter column always visible — NO toggle.
- 390px: filters wrapped in a `hidden md:block` section toggled by **`Phoenix.LiveView.JS.toggle`**
  on a visible "Filters" button with an expand/collapse indicator. Stateless, URL-param-free, NO
  new socket assign, NO client JS hook — consistent with existing `JS.focus`/`JS.focus_first`.

### Support-card triage DOM order (IA-LD-05)
Tier 1 actionable cards (`failed_ingest`, `orphan_backlog`) first at all viewports; within Tier 1,
error-count before warning-count. Tier 2 compact/zero-state rows after. Matches
`support_cards.ex:34-35` — lock prevents reorder. Tier-1 cards: `bg-base-200 border border-base-300`,
no shadow.

### Nav labelling (IA-LD-06)
L1 nav items carry the surface noun ONLY ("Deliveries") — never a count suffix or verb.
`aria-current="page"` marks the active L1. Page `h1` carries the L2 surface name. Applies to both
`nav_link` (≥768px sidebar) and `nav_pill` (390px header).

### Group test hooks (D-08)
Tag new/uplifted group containers with `data-testid="operator-{group}"` kebab cells (extends
existing `operator-master-detail`, `operator-detail-column`, `operator-overview`,
`operator-detail-error`, `operator-empty-detail`). Playwright `structural.spec.js` queries via
`getByTestId`. Rebuild + **commit `priv/static/app.css`** (`verify.preview` reds CI on an
uncommitted bundle).

## Motion (MOTION-LD-* — LOCKED; this phase consumes, does not author)

Operator surface uses ONLY the named motions already defined. ease-out, ≤300ms, transform/opacity
(color permitted only at the fast token ≤100ms for state layers), CSS+LiveView.JS only, no client
hook, `prefers-reduced-motion` snaps to instant (MOTION-LD-09).

| Element | Named motion | Spec |
|---------|--------------|------|
| Detail pane / cards entrance | `.motion-reveal` (MOTION-LD-02) | opacity 0→1 + translateY 6px→0, 220ms in / 150ms out, `phx-mounted` |
| Event timeline | `.motion-timeline` (MOTION-LD-03/08) | child `.motion-reveal`, 40ms × index stagger, cap 8 items |
| Replay modal overlay | `.motion-overlay` (MOTION-LD-04) | scale 0.98→1 + opacity, 220ms in / 150ms out |
| Flash / toast | `.motion-reveal` on flash region (MOTION-LD-07) | 220ms in, instant dismiss |
| List rows / nav links | `row-state` `transition-colors duration-(--duration-fast)` (MOTION-LD-06) | color/bg/border only, ≤100ms |
| Orientation strip | none (IA-LD-01) | token-clean, no motion |

## Accessibility (A11Y-01/02 — LOCKED via STATE-LD-* + DARK-LD-03)

- **Focus rings:** `focus-visible:ring-2 focus-visible:ring-primary` (+ `ring-inset` on row
  buttons that span full width; `ring-offset-1` on nav). Glass light / Ice dark (DARK-LD-03).
  Verified ≥3:1 (WCAG 1.4.11). Already added on shared components in Phase 97.
- **ARIA:** `aria-current="page"` on active nav (IA-LD-06); `aria-current="true"` +
  `aria-selected="true"` on selected row (STATE-LD-11); `role="dialog"` + `aria-modal="true"` +
  `aria-labelledby` + `phx-key="Escape"` + focus trap on replay modal (STATE-LD-17).
- **Heading hierarchy:** exactly one `h1` per page (the L2 surface name, `shell.ex:183`);
  detail/card headings are `h2` using `text-heading`.
- **Touch targets:** `min-h-11` (44px) on every interactive control. Verified present on row
  buttons, nav links/pills, filter inputs/selects, replay button.
- **Contrast:** WCAG AA text on actual surface in both themes (A11Y-02); dark border upgrade to
  `border-input` where a border is the sole elevation boundary (DARK-LD-02/07).
