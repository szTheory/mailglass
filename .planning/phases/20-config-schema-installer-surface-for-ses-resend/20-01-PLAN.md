    - `type: :keyword_list`
    - `default: []`
    - `doc: "SES webhook configuration."`
    - `keys:` containing only:
      - `enabled: [type: :boolean, default: true, doc: "Enable the SES webhook route when explicitly mounted."]`
      - `cert_cache_ttl_seconds: [type: :pos_integer, default: 86_400, doc: "TTL in seconds for cached SNS signing certificates. Default: \`86_400\`."]`

    - `type: :keyword_list`
    - `default: []`
    - `doc: "Resend webhook configuration."`
    - `keys:` containing only:

      - `secret: [type: {:or, [:string, nil]}, default: nil, doc: "Svix webhook secret used for Resend signature verification. Required for verification; omit only if the provider is disabled."]`
      - `timestamp_tolerance_seconds: [type: :pos_integer, default: 300, doc: "Maximum accepted age for the Svix timestamp in seconds. Default: \`300\`."]`

    Keep these subtrees closed. Do not add speculative keys such as endpoint URLs, region, retries, or router options.

    Mirror the current Mailgun test style: create config with `Mailglass.Config.new!/1`, fetch the subtree with `Keyword.fetch!/2`, and assert exact values.
