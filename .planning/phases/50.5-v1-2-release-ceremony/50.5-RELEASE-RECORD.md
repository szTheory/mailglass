## Notes

**release-please-action v5 + GITHUB_TOKEN + GitHub anti-recursion (NEW for Phase 51).** The release-please-action v4.4.1 → v5.0.0 upgrade (dependabot PR #26, merged 2026-05-08) silently changed the post-merge release fan-out behavior. v5 (still) creates GitHub Releases via `secrets.GITHUB_TOKEN`; GitHub's documented anti-recursion guarantee then blocks those releases from firing `release: published` events on `publish-hex.yml`. Phase 44.5's RELEASE-RECORD explicitly noted "Fallback path used: not used" — that was true under v4. Under v5 the fallback path (`workflow_dispatch` of `publish-hex.yml` after merge) is now the canonical path. **Phase 51 deferred-items entry to add:** decide whether to (a) provision a `RELEASE_PLEASE_PAT` (PAT with `contents: write`) for the action so release-published events fan out again, or (b) codify `workflow_dispatch` as the canonical post-tag publish trigger (update MAINTAINING.md + the orchestrator script). Option (a) restores 44.5-shaped automation; option (b) accepts the manual gate as the new posture.

**Admin → inbound Hex index race (NEW for Phase 51).** `mailglass_admin/mix.exs:mailglass_inbound_dep/0` (added in Phase 48 per D-48-01) declares `{:mailglass_inbound, "~> 0.2", optional: true}` under `MIX_PUBLISH=true`. `publish-hex.yml` runs publish-admin and publish-inbound in parallel after publish-core. The existing "Wait for Hex.pm index" step in publish-core waits for `mailglass` to be indexed before fanning out; there is NO equivalent wait for `mailglass_inbound` before publish-admin runs. This caused dispatch #5 to fail; recovery was a manual retry. **Phase 51 deferred-items entry to add:** add a "Wait for mailglass_inbound on Hex.pm index" step in publish-admin (before its `MIX_PUBLISH=true mix deps.get`) that polls `mix hex.info mailglass_inbound <ver>` until the new version is indexed, mirroring the existing core wait step. Alternatively: order publish-inbound to complete before publish-admin (serial instead of parallel) at the cost of slower publishes.

**Operator Browser Gate.** Carried as advisory in `publish-hex.yml gate-ci-green` ADVISORY_LANES per 44.5 commit `5734c1b`; re-strict remains Phase 51 scope (items #9-10).
