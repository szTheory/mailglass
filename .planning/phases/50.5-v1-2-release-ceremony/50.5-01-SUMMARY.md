- **Found during:** Task 2 (refreshing tarball allowlists and running publish.check)
- **Issue:** `mix mailglass.publish.check --package mailglass_admin` failed with `undefined function mailglass_inbound_dep/0`. Phase 48 added `defp mailglass_inbound_dep/0` to `mailglass_admin/mix.exs` as a private helper for the optional `mailglass_inbound` dep, but `mailglass.publish.check.ex` only had special-case handling for `mailglass_dep/0` — not for `mailglass_inbound_dep/0`. Three checks were broken: `verify_deps/1` (tried to eval the call in isolation), `verify_linked_constraint/1` (same), and `verify_prod_deps/1` (called `deps.get` with `mailglass_inbound ~> 0.2` resolving to Hex before 0.2.0 is published)
- **Fix:** Added `helper_body_inbound` field to publish.check context; added `{:mailglass_inbound_dep, _, []} -> inbound_helper` pattern-match in both `verify_deps/1` and `verify_linked_constraint/1`; extended `rewrite_mailglass_publish_dep/2` to also rewrite `mailglass_inbound_dep/0` body to use the local path during pre-publish prod-deps resolution check
- **Files modified:** `lib/mix/tasks/mailglass.publish.check.ex`
- **Verification:** `mix mailglass.publish.check --package mailglass_admin` exits 0
- **Committed in:** `5421b14` (Commit A)
