<objective>
Build the anti-vacuity layer: a pure policy module that answers "how many tests actually ran, which
categories were allowed not to run, and did the regression signature reappear," plus the negative controls
that prove it fails when it should.

ROADMAP criterion 3 asks for three things — the executed count has not silently dropped, the
`:already_shared` signature is exactly zero, and the lane still catches a real regression. This plan owns
the first two. Counts come from `ExUnit.after_suite/1` and never from the CLI summary line (D-13). The
load-bearing invariant is not the count floor: per D-14 it is the **pinned exclusion-tag allowlist**,
checked in both directions. A new `@tag` plus a matching `--exclude` fails on the tag *name*
before any arithmetic matters, and both-directions equality also kills dead allowlist entries.

Purpose: "implied by zero failures" is true today and worthless tomorrow. The moment the lane goes red for
three unrelated reasons plus forty leaked owners it reads as forty-three failures and the regression
identity is lost — which is precisely the SEED-007 pain, where every one of these was reported as a citext
probe exhaustion for months.
Output: `SuiteFloor`, the signature classifier in the formatter, and a negative control per violation class
in the required lane.
</objective>
