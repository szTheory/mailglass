## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator (tenant A) → replay of any record id | Replay mutates the ledger; a guessed foreign-tenant UUID must be rejected before the un-scoped replay/2 |
| operator → raw provider payload (PII) | Raw source is redacted by default; reveal requires the :reveal_raw capability |
| inbound broadcast → InboundLive list | The id-only payload must be re-fetched tenant-scoped; a foreign/filtered record must not appear |
| rendered HTML → operator's eyes | No unmasked recipient/sender; no raw bytes by default; no PII in emitted telemetry |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
