## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| README renderer -> repo-local SVG | GitHub renders repository Markdown and SVG assets for untrusted public readers. |
| Local SVG export -> committed PNG | A generated binary enters source control and may become the public link-preview image. |
| Documentation -> maintainer upload process | Maintainers may treat documented upload steps as an API-backed workflow if the limitation is not explicit. |

| T-92-SC | Tampering | npm/pip/cargo installs | accept | No new package install is planned; `npx playwright` uses the existing local Playwright toolchain already verified by project research. |
