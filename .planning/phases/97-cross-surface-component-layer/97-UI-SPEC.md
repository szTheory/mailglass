**Enforced constraints (binding for Phase 97):**
- Permitted weights: 400 and 700 ONLY. Weights 500 and 600 are not loaded.
- Utility classes `text-lg`, `text-xl`, `text-2xl`, `text-3xl` (raw Tailwind) are BANNED — use `text-heading` or `text-display` token classes.

### Accent Allowlist (10% rule — DARK-LD-04)

Accent (Glass in light, Ice in dark) is **reserved exclusively** for:
1. Active nav_link left border (`border-primary`, 2px line)
2. Active nav_pill background tint (`bg-primary/10`)
3. Focus rings on all interactive elements (`ring-primary`, `focus-visible:ring-primary`)
4. Active timeline event highlight border (`border-primary ring-1 ring-primary/40`)
5. Preview sidebar active scenario left border (`border-primary`, 2-3px line)
6. Preview tabs active tab underline (`border-b-2 border-primary`)
7. `hero-lifebuoy` icon in orientation strip (`text-primary` — single icon, not fill)
8. Status badge `badge-primary` for in-flight statuses only (`:dispatched`, `:queued`, `:sent`)
9. Device frame active button (`btn-primary`)

Accent is **prohibited** on: default structural borders, card fills, section backgrounds, badge fills other than the three in-flight statuses above.

## Interaction States

### Global Rules

- **Focus rings:** `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-1` on all interactive elements. Ring color is `ring-primary` (Glass in light, Ice in dark — DARK-LD-03). Width: 2px, offset: 2px (from `--mg-focus-ring-width` / `--mg-focus-ring-offset` in tokens.css).
- **Touch targets:** `min-h-11` (44px) required on ALL interactive controls — buttons, nav links, inputs, selects, row buttons. No exception for operator surfaces. Dev-only controls (preview tabs): `min-h-11` still required per STATE-LD-20 decision.
- **Disabled state:** render button as absent (`:if` conditional) OR `btn-disabled` + `disabled` attr. Never a visually-present-but-visually-similar-to-enabled button without an explicit disabled affordance.
- **Hover transitions:** `transition-colors duration-(--duration-fast)` (150ms). Permitted transition properties: `color`, `background-color`, `border-color` only. No layout-property transitions (MOTION-LD-10).
- **Elevation:** flat borders-first. No `shadow-*` on layout containers or cards. `shadow-overlay` permitted for modals ONLY.

## Motion Contract

Source: MOTION-LD-01..14 (SUMMARY.md). Constraints are hard — no exceptions.

| Motion name | CSS class | Properties | Duration | Easing | Exit duration | Trigger |
|-------------|-----------|-----------|---------|--------|--------------|---------|
| reveal | `.motion-reveal` | `opacity` 0→1, `translateY` 6px→0 | 220ms | `var(--ease-out)` | 150ms (reverse) | `phx-mounted` |
| timeline-in | `.motion-timeline > *` | `opacity` 0→1, `translateY` 4px→0, stagger 40ms×index | 220ms per child | `var(--ease-out)` | — (no exit) | `phx-mounted` on container |
| overlay | `.motion-overlay` | `scale` 0.98→1, `opacity` 0→1 | 220ms | `var(--ease-out)` | 150ms | `phx-mounted` (open); LiveView.JS `hide` (close) |
| tab-swap | `.motion-tab-swap` | `opacity` 0→1 (crossfade) | 150ms | `var(--ease-symmetric)` | 150ms (symmetric) | Element insertion via LiveView tab change + unique `id` |
| row-state | `transition-colors duration-(--duration-fast)` | `color`, `background-color`, `border-color` only | 150ms | ease-out | same | CSS hover/active state |
| flash | reuses `.motion-reveal` | same as reveal | 220ms | `var(--ease-out)` | instant (no exit animation) | `phx-mounted` |

**Hard motion constraints (MOTION-LD-09, MOTION-LD-10, MOTION-LD-11):**
- `@media (prefers-reduced-motion: reduce)` global block in `app.css` sets all durations to `0.01ms !important` — already implemented (app.css:292-300).
- Entrance animations fire only on mount (`phx-mounted`) — NEVER on every LiveView patch.
- Prohibited animation properties: `height`, `width`, `max-height`, `padding`, `margin`, `left`, `top`, `right`, `bottom`, `font-size`, `line-height`, `border-width`.
- No springs, no overshoot, no CSS animations with overshoot cubic-bezier curves.
- Keyboard-repeatable actions carry NO motion (MOTION-LD-14).
- No client-side JS hooks — CSS + LiveView.JS only.

**Stagger cap (MOTION-LD-08):** 8 items × 40ms = 280ms max stagger spread. Each child's own transition = 220ms. Already implemented in `app.css:281-288`.

## Gallery Contract

Source: CONTEXT D-01..D-04, CONTEXT D-09, D-10.

### Route

- Path: `/dev/mail/gallery`
- Module: `MailglassAdmin.GalleryLive` (new, `:index` action)
- Mount: one `live "/gallery", MailglassAdmin.GalleryLive, :index` line inside existing `live_session :mailglass_admin_preview` block in `router.ex:219-225`
- Auth: inherits `if dev_routes` wrapping from adopter — dev-only by construction, never `/ops`
- DB access: NONE — in-code specimen list only, no mailable scan, no `__preview_session__` assigns

### Specimen Layout

- Group specimens by component (one section per component), then by state within the component section.
- Each specimen cell renders **both themes side-by-side**: twin `data-theme="mailglass-light"` and `data-theme="mailglass-dark"` wrappers inside each cell container.
- The cell container background uses `bg-base-200 border border-base-300 rounded-box` with a visible label showing component name + state.
- Specimens must cover every state/atom enumerated in STATE-LD-01..22. Notably: 22 status atoms for `status_badge` (STATE-LD-05); both states for `suppression_card` (STATE-LD-15); all three states for `routing_trace` (STATE-LD-18); all four states for `evidence_card` (STATE-LD-19).

### data-testid Scheme

- Format: `gallery-{component}-{state}` (e.g. `gallery-status_badge-delivered`, `gallery-nav_link-active`, `gallery-flash-error`)
- Theme is carried by the wrapping `[data-theme]` ancestor — NOT baked into the testid. One stable testid per component×state cell.
- Structural assertions query `getByTestId("gallery-{component}-{state}")` and scope under `[data-theme="mailglass-light"]` or `[data-theme="mailglass-dark"]` ancestors.

### Ratchet Integration

- Un-skip `e2e/structural.spec.js:421-428` reserved gallery block; add real `getByTestId` visibility/accent assertions via a new `openGallery(page)` helper (mirroring `openPreview` pattern at `structural.spec.js:38-42`).

- Do NOT add a "gallery" entry to `@surfaces` in `ratchet_baseline_test.exs` or `ui-baseline-scores.json` — the frozen 36-cell baseline (3 surfaces × 6 pillars × 2 themes) must remain unmodified (CONTEXT D-10).
