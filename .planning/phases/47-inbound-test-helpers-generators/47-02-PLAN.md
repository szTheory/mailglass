## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47-05 | Tampering | gen.inbound_route appending arbitrary code to a router | mitigate (HIGH) | Insert a structured `route/2` AST node via Igniter (`add_code` builds the node from `route(Mailbox, recipient: ...)`), not raw string splicing of arbitrary task input; module/recipient args flow through `Module.concat`/`inspect`, not eval. (D-47-08) |
| T-47-06 | Tampering (corruption) | re-running gen.inbound_route corrupts the router (double-insert) | mitigate (HIGH) | Idempotent dup-scan via `move_to_function_call_in_current_scope` + `argument_equals?`; mandatory run-twice `assert_unchanged` self-test proves no second insert. (Pitfall 3) |
| T-47-07 | Tampering | malformed AST on a single-statement router body | mitigate (MEDIUM) | Rely on `add_code/3` single-child block promotion; explicit single-statement-body self-test asserts the route lands after `use` and compiles. (Pitfall 4) |
| T-47-08 | Tampering | generated mailbox enabling unsafe defaults | accept (LOW) | Inbound has no open/click tracking surface; generated `process/1` returns neutral `:accept`, no auth heuristics. (security note) |
</threat_model>
