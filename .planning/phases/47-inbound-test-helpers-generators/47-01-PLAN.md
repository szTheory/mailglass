| Boundary | Description |
|----------|-------------|
| Fixtures (test code) → real SES verifier + real CertCache ETS | The fixture mints a private key and primes the process-global cert cache that the real verifier reads |
| Fixtures output → git working tree | Any disk write here risks committing a key/cert or real-PII sample |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-47-02 | Information Disclosure | `Fixtures` sample data | mitigate (HIGH) | Code-built only; no `.eml` on disk; no real-PII. Acceptance grep asserts no on-disk fixture path. (D-47-11, security V7) |
