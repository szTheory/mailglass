<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv -> Mix task | Untrusted shell input becomes runtime options and output mode selection |
| Shared result -> public terminal / JSON output | Internal findings become the shipped external contract |
| README promises -> shipped command | Public docs create operator expectations about certainty and supported flags |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-13 | Spoofing | CLI contract | mitigate | Require explicit `--domain`, explicit `--dkim-selector`, and explicit `--format`; reject positional and ambient inference paths. |
| T-25-14 | Tampering | JSON contract drift | mitigate | Route JSON rendering through `Formatter.render_json/1` over the shared `Result` shape and pin `schema_version` plus required keys in task tests. |
| T-25-15 | Integrity | public docs and output semantics | mitigate | Keep README and CLI output explicit that Phase 25 reports DNS-derived findings and `cannot_verify` states, not inbox-placement certainty or provider reputation. |
| T-25-16 | Denial of Service | malformed CLI input | mitigate | Fail fast on unknown flags, blank domain values, and invalid format values before any DNS work begins. |
</threat_model>
