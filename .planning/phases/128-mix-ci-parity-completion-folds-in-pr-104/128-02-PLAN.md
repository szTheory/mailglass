<objective>
Hoist the required+advisory CI lane set to a single `ci_lanes` source and add the MIXCI-03
manifest-membership parity-drift test. Phase 126 deliberately left the required-lane set duplicated
across ci.yml (ci-green.needs), publish-hex.yml (REQUIRED_LANES), and setup_branch_protection.sh
(REQUIRED_CHECKS) with a "Phase 128 MIXCI-03 will hoist to one source" marker. This plan creates
that single source, points the existing GATE-03 meta-test at it, and adds a new test asserting
`ci ∪ ci.browser` (the alias union) covers every required + advisory CI lane by identity — failing
loudly on drift, with anti-vacuity guards.

Purpose: "One definition of green" (LD-10). The two surfaces (human aliases vs CI per-job matrix)
are intentionally separate; this test is what keeps them from drifting silently.

Output: `test/support/ci_lanes.exs` shared source + `test/scripts/ci_parity_drift_test.exs` +
GATE-03 meta-test rewired to the shared source. Covers MIXCI-03. Depends on Plan 01 (the ci/ci.browser
alias bodies must exist for the parity test to parse).
</objective>
