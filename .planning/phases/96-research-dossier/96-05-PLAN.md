    Create `.planning/research/v1.11/MICROCOPY.md`.

    Structure the dossier body with these sections (exact heading names at your discretion):
    1. Voice Constraints — extract the locked voice rules from CLAUDE.md Brand & Voice and brandbook/brand-book.md. Tabulate: (a) the thoughtful-maintainer register attributes (clear/exact/confident/warm/modern/technical), (b) the "say this, not that" pairs from the brand book, (c) the seven domain nouns with definitions, (d) the banned standalone terms (Email, Status, Notification), (e) the canonical error exemplar pattern (cause-naming, not "Oops").

    2. Per-Surface JTBD Map — for each surface, state the JTBD and derive the copy obligations:
       - Operator (/ops/mail): JTBD = "audit why a Delivery failed". Copy obligations: delivery list empty state ("No Deliveries match your filters"), error states naming the cause (per the error exemplar pattern), CTA labels using "Delivery" not "Email".
       - Inbound (/ops/mail/inbound): JTBD = "understand why an InboundMessage did not route". Copy obligations: routing trace empty state, filter section labels (per GAP-04 — must use text-label token AND be written per voice), evidence card reveal labels.
       - Preview (/dev/mail): JTBD = "preview a Message before sending it". Copy obligations: orientation empty state CTA (per GAP-02 — must be focusable AND the label must be voice-compliant), device frame label, preview tabs labels.

    3. Anti-Pattern Catalogue — enumerate the banned patterns with before/after examples:
       - "Oops! Something went wrong" → "Delivery blocked: recipient is on the suppression list"
       - Generic "No results" → specific cause-naming ("No Deliveries in the last 7 days for this tenant")
       - "Email" alone → "Delivery" or "Message" depending on context
       - "Status" alone → "Delivery status" or name the event type
       - "Notification" → describe the actual event

    4. Empty/Loading/Error/Confirmation Copy Inventory — for each surface, read the current copy from the codebase (file:line) and flag: (a) voice violations (Oops, vague errors, banned terms), (b) missing states (surfaces with no empty-state copy), (c) copy that could be improved per the JTBD.

    5. Draft Decisions — propose specific locked copy strings or patterns for: (a) each surface's primary empty-state heading + sub-copy, (b) error state heading pattern (must name cause), (c) filter section labels for inbound (closing GAP-04 copy angle), (d) preview orientation CTA label (closing GAP-02 copy angle), (e) replay modal confirmation copy, (f) suppression card copy, (g) loading state label pattern.

    6. Adversarial Synthesis — challenge each draft copy decision against (a) the voice constraints (cause-naming, no "Oops", seven domain nouns, no banned terms) and (b) the open GAP rows. Specifically: does the preview orientation empty-state CTA label make the purpose clear for keyboard users (GAP-02)? Do the inbound filter labels use the correct voice register and avoid off-token rendering (GAP-04 copy angle)? Revise any decisions that fail the critic.

    7. LOCKED DECISION block — the table defined below.

    The LOCKED DECISION block MUST:
    - Use heading `## LOCKED DECISION`
    - Contain a markdown table with columns: `LD-ID | Decision | Applies-to (surface/archetype) | Constraint-binding | Closes-GAP`
    - Use ID prefix `COPY-LD-NN` (e.g. COPY-LD-01, COPY-LD-02, ...)
    - Decision cell: state the LITERAL copy string or pattern (e.g. "Preview empty state heading: 'Preview a Mailable'", "Inbound empty state: 'No InboundMessages match the active filters'", "Error heading pattern: '[Noun] [past-tense verb]: [specific cause]'")
    - Constraint-binding cell: name the specific voice/design constraints (e.g. "thoughtful-maintainer voice; cause-naming pattern; seven domain nouns; no 'Oops'; no 'Email' alone")
    - Closes-GAP cell: reference the GAP-NN ID or "—"
    - Must include at minimum: one row per surface (Operator, Inbound, Preview) for the primary empty state, one error-state pattern row, one confirmation-copy row, the banned-patterns row
    - GAP-02 (preview empty-state focusable CTA) copy must appear in the Closes-GAP column of at least one row
    - The seven domain nouns must each appear at least once across the Decision cells (Mailable, Message, Delivery, Event, InboundMessage, Mailbox, Suppression)
    - No Decision cell may contain "Oops", "Email" (standalone), "Status" (standalone), or "Notification" (standalone)

    Do NOT modify any admin code, CSS, brandbook files, or the RATCHET-GAP-REGISTER.md.
