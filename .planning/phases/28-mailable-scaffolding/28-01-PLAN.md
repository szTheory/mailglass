<feature>
  <name>Mailable Code Generator</name>
  <files>lib/mix/tasks/mailglass.gen.mailable.ex, test/mix/tasks/mailglass.gen.mailable_test.exs</files>
  <behavior>
    The task `mix mailglass.gen.mailable <Name>` should:
    1. Resolve the module name. If the provided name lacks the app prefix and `.Mail.`, it should automatically prepend it (e.g. `Notification` -> `MyApp.Mail.Notification`).
    2. Generate an Elixir module using `Igniter.Project.Module.create_module/3`. The module should:
       - `use Mailglass.Mailable, stream: :transactional`
       - `import Phoenix.Component`
       - `embed_templates "<lowercase_name>/*"`
       - Define a builder function matching the `<lowercase_name>` that sets up the subject, HTML body, and calls `Mailglass.Message.put_function(:<lowercase_name>)`.
    3. Generate a HEEx template file using `Igniter.create_new_file/3` at the correct path: `<module_directory>/<lowercase_name>/<lowercase_name>_template.html.heex`. This naming prevents Arity-1 collisions between `embed_templates` and the builder function.
    
    Test cases should assert:
    - Providing `Notification` creates the correct `lib/my_app/mail/notification.ex` and `lib/my_app/mail/notification/notification_template.html.heex`.
    - The generated code compiles and contains the expected boilerplate.
  </behavior>
  <implementation>
    In `test/mix/tasks/mailglass.gen.mailable_test.exs`:
    - Setup tests using `Igniter.Test` utilities, simulating running the task.
    - Assert that the correct module and template paths are generated with expected contents.
    
    In `lib/mix/tasks/mailglass.gen.mailable.ex`:
    - `use Igniter.Mix.Task`
    - Implement `info/2` to define the schema: expecting a required positional argument `:mailable`.
    - Implement `igniter/1`:
      - Retrieve the application module namespace via `Igniter.Project.Application.app_module(igniter)`.
      - Check if the provided mailable name starts with `#{app_module}.Mail.`. If not, format it properly.
      - Calculate the module name, lowercase name for functions/paths, and base file path using `Igniter.Project.Module.proper_location` or equivalent Igniter tools.
      - Construct the Mailable module AST or string.
      - Construct the HEEx template string (including standard components like `<Mailglass.Components.heading>`).
      - Apply both to the `igniter` pipeline and return it.
  </implementation>
</feature>
