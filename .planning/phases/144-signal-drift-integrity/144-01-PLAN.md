## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub secret/workflow → branch-protection API | A privileged PAT and external endpoint determine whether live protection can be observed or changed. |
| Workflow YAML job id → GitHub reported status context | Branch protection consumes display names, not repository-local YAML ids. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-144-01 | Tampering | PAT/verifier outcome in both workflows | high | mitigate | Closed three-state outputs plus authoritative `if: always()` failure ensure missing credentials, tooling, or endpoint access cannot produce green. |
| T-144-02 | Tampering | Required status-context identity | high | mitigate | Parse the reported job display name, compare it to canonical REQUIRED_CHECKS, and run a wrong-id negative control. |
| T-144-03 | Elevation of privilege | Scheduled mutation path | medium | mitigate | Keep live mutation solely in the existing reassertion job and keep advisory verification read-only. |
</threat_model>
