<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| prepared Message/route → V1 envelope | Rich adopter/provider terms become long-lived JSON and must be complete, bounded, and non-executable. |
| path/upload → persisted attachment bytes | Mutable node-local content crosses into retry-stable private storage. |
| persisted envelope → worker dispatch | Untrusted stored JSON selects both message content and the originally resolved adapter route. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-150-20 | Tampering / Denial of Service | `Envelope.dump/2` and `load/1` | high | mitigate | Explicit field/header schema, recursive depth/item/byte limits, finite-number predicate, canonical non-bang encoding, and hostile boundary tests. |
| T-150-21 | Information Disclosure | serialization errors | high | mitigate | Stable reason classes and field categories only; tests recursively reject fixture values from error context. |
| T-150-22 | Tampering | attachment materialization | high | mitigate | Single enqueue-time read, data-only representation, exact attribute validation, and mutate/delete-after-dump proof. |
| T-150-23 | Elevation of Privilege | persisted `adapter_ref` | high | mitigate | Validate non-empty UTF-8 route, return it from the decoded envelope, and fail on Delivery/envelope mismatch before adapter resolution. |
| T-150-SC | Tampering | package installs | high | mitigate | No package install occurs; existing locked dependencies only. |
</threat_model>
