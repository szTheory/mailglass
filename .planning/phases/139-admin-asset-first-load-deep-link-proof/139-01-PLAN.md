## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/client -> admin HTML | Untrusted request paths and query strings influence the first HTML route and must not produce relative or external asset hrefs. |
| Test-only router -> operator admin surface | Alternate operator routes must preserve the same authentication and session contract as the existing operator mount. |
| Router macros -> asset controller | Asset routes must remain macro-scoped under the selected mount root, not duplicated by hand-written fallback routes. |

## ASVS Level 1 Coverage

This plan applies ASVS Level 1 coverage for V2 Authentication, V3 Session Management, V4 Access Control, and V5 Input Validation where the first-HTML proof touches operator/inbound routes, session-backed test mounts, route/query inputs, and asset href generation. Blocking threshold: any HIGH severity auth/session bypass, external asset URL, nested relative CSS/font URL, or CSS/font 404 proof failure blocks execution until the plan is revised or the implementation proof is fixed.
