# Research Summary — v1.9 Brand Book Fable

**Synthesized:** 2026-06-11
**Inputs:** BRAND-SYSTEMS.md, LOGO-CRAFT.md, TOKENS-A11Y.md, PITFALLS-PORTABILITY.md
**Consumers:** roadmapper + phase planners for Phases 85–90
**Overall confidence:** HIGH. Contrast numbers are computed (not estimated), GitHub SVG behavior is multi-source verified, brand-system patterns fetched from live pages. MEDIUM only on Safari in-SVG media queries, Gmail dark-mode internals, and some devtool-brand typography details.

## Key Findings

**BRAND-SYSTEMS** — World-class brand artifacts split into two genres that must not blend: tiny public logo/trademark pages (Tailwind, Linear, Astro, Oban) and engineer-operable design-system docs (Geist, Radix, shadcn, Primer). `brandbook-fable/` is the second genre with a thin logo-kit layer folded in. Credibility is mechanical, not eloquent: every color step has a named job, every token a role description, the doc terminates in copy-pasteable CSS, and dark mode is *demonstrated live* via a page-level toggle that re-skins every specimen (Geist) — the single pattern that closes the v1.8 "dark undemonstrated" gap. A runtime-computed WCAG contrast matrix (≈20 lines of inline JS) that can never drift from the tokens is the book's strongest rigor signal.

**LOGO-CRAFT** — Honest ecosystem finding: most successful devtool brands (Vercel, Linear, Figma, Stripe, Supabase) do NOT modify wordmark letterforms; they win on type quality plus a strong abstract mark and tight lockup. Integrated typemarks must clear the FedEx/Braun bar: exactly one earned modification, every other glyph flawless, word fully legible to viewers who never see the trick. For "mailglass" the prime site is the **l·g·l cluster at the mail|glass seam** (counter-as-lens g, negative-space pane, free baseline-breaking descender); the ss pair is the riskiest site. The file specifies a complete drawing system — integer grid (x-height 100, S=22 stems), optical-correction table (thinned horizontals, 3-unit overshoot, joint thinning), per-glyph geometry, and an 8-point AI-letterform self-audit — plus small-size rules (favicon is a redrawn 16×16 artifact, ≤3 shapes; wordmark floor ≈16px height; lockup gap 0.5–0.75× x-height).

**TOKENS-A11Y** — DTCG hit its first stable version (2025.10): use `$value`/`$type`/`$description` with hex-string values and `{group.token}` aliases; two tiers only (raw palette → semantic roles), no component tier, no build step. Dark mode = parallel role sets with identical keys, one CSS variable name per role reassigned under `[data-theme="dark"]`. The computed contrast matrix corrects the prompt's assumption — Glass #277B96 is 4.82:1 on white (passes AA) — but finds four real failures: Glass on Mist/selected/info surfaces (4.16–4.37), Amber on Mist (4.40), codex dark error #D47368 on raised dark surfaces (3.85–4.09), and sub-3:1 input borders both themes. Six fix values are computed and ready (see Settled). The codex dark ramp (#0D1B2A → #152538 → #1F3049, Mist text, Ice accents) verified clean and is adopted.

**PITFALLS-PORTABILITY** — All three v1.8 failures share one root cause: artifacts verified only in the authoring environment, never the consuming one. The consuming environments are GitHub's `<img>` sandbox (no fonts, no scripts, no external fetches, `currentColor` → black), `file://` (no fetch/modules, flaky localStorage), email clients (no SVG at all, three incompatible dark-mode models, Gmail force-transforms colors), and social crawlers (no SVG og:images, period). Inter is preinstalled on no major OS — most viewers see their system font; design must tolerate that honestly. 28 registered pitfalls each map to an authoring phase and a Phase 90 grep/render gate.

## Decisions Already Settled by Research

- **Token format:** DTCG-2025.10 names (`$value`/`$type`/`$description`), hex-string values (deviation documented), `{group.token}` aliases, no `$schema` Tokens Studio line. Two tiers: `palette.*` (brand-named modifiers, not numeric ramps) → semantic roles. No component tier, no composite tokens, no `state.*` group divorced from roles.
- **CSS naming:** `--mg-{category}-{role}[-{variant}][-{state}]`; state is last segment, default unsuffixed (`link`/`link-hover`); one global `focus-ring` role. Dark via `[data-theme="dark"]` reassignment + `@media (prefers-color-scheme: dark){:root:not([data-theme="light"])}`; toggle cycles auto→light→dark; `color-scheme` set per theme; localStorage in try/catch.
- **Confirmed contrast numbers (computed):** Ink/Paper 16.74; Slate/Paper 5.26 (AA, not AAA); Glass/Paper 4.64 and Glass/white 4.82 (PASS AA); Glass FAILS on Mist 4.37, selected 4.16, and on Ink 3.61; Ice-on-Glass 3.59 fails normal text — never Ice text on Glass fills.
- **Palette additions (computed, ready to ship):** light — `glass-deep #1D637A` (default link/accent-text/info-text, ≥5.65 everywhere), `glass-deepest #174E61` (hover/active), `amber-deep #96520E` (warning-text), `slate-soft #74909F` (input border ≥3:1); dark — `crimson-bright #E29089` (error-text, replaces failing #D47368), `slate-bright #62809A` (input border), `slate-dim #6B7E8F` (disabled). Six seed brand colors stay untouched as identity anchors.
- **Font stacks (no @font-face, no webfont URLs):** `Inter, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", "Noto Sans", Arial, sans-serif`; display prepends `"Inter Tight"`; mono `"IBM Plex Mono", ui-monospace, "SF Mono", SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace`. Book states plainly that Inter is canonical-when-installed, system-ui is the honest default. Wordmark is outlined paths only — the one place type never falls back.
- **GitHub SVG rules:** outlined paths, `viewBox` required, explicit hex fills (no bare `currentColor` in file assets — ship light/dark variants), no `foreignObject`/scripts/external refs/`<defs>` IDs (or asset-prefixed), `role="img"` + first-child `<title id>` + `aria-labelledby`. Dark swap via `<picture>` only where a single both-backgrounds design genuinely can't work; `#gh-dark-mode-only` is dead; blob viewer is never sign-off.
- **index.html architecture:** one self-contained file, zero fetches/modules, tokens inlined (Phase 90 diffs against tokens.css), inline SVG specimens consume `var(--token)`, sticky header with theme toggle + anchor rail, section order foundations→applications, contrast matrix computed at runtime, email specimen isolated in `<iframe srcdoc>`, `@media print` forces light + scoped `print-color-adjust: exact`.
- **Email specimen:** tables + inline styles, 600px, six-digit hex, no SVG, web-safe fonts only (wordmark-as-system-text is the documented exception), both color-scheme metas, no #000000/#FFFFFF literals, ≤100KB.
- **OG card:** SVG is a labeled source template only; no platform renders SVG og:images; document manual 1200×630 PNG export path, never reference `.svg` in an `og:image` snippet.
- **Logo drawing system:** Inter-Tight-compatible skeletons (double-story a, single-story g, grotesque terminals), x-height-100 grid with S=22, the optical-correction table, ≤2-decimal coordinates, filled outlines not strokes, redrawn 16×16 favicon, lockup gap 0.5–0.75× x-height, i dot untouchable.

## Open Decisions for Phases

- **Phase 85 (differentiation brief):** Name the banned motif families (P-21..P-25 + envelope-swoosh, Linear-slats/Glassdoor/Gmail resemblance); set the compositional stance (left-aligned, documentation-like, anti-centered-hero); articulate the ownable axis (Ink/Glass/Ice + transparency-as-meaning, per Supabase's color-ownership lesson); state the non-negotiables that get repeated loudly (Supabase single-rule pattern).
- **Phase 86 (foundations/tokens):** Final semantic role inventory (research proposes ~30 roles/theme — confirm or trim); pick the four dark feedback *backgrounds* (research left them as "low-chroma surface-family tints" — must contrast-verify against the new `{kind}-text` values); decide `--radius` and motion-duration token values; confirm the bézier roundness constant (0.5523 vs superelliptical 0.57–0.60) used book-wide.
- **Phase 87 (logo tournament):** Which letterform plays fill the 8 slots across the 4 axes (l·g·l counter-as-lens vs negative-space pane vs refraction shear vs descender geometry; m-monogram vs g-monogram); whether the 2 pure-typemark slots clear the craft bar at all (losing to mark+wordmark lockups is a legitimate outcome); per-option small-size fallback policy (IBM unstriped-variant precedent). Maintainer hard-pause decides the winner.
- **Phase 88 (book assembly):** Exact section order/IA within the synthesized skeleton; how much of the codex book's prose survives vs rewritten; click-to-copy and forced-state-row implementation details; right-rail nav breakpoint behavior.
- **Phase 89 (collateral/copy):** Which surfaces get specimens (README/docs/OG/email/landing proposed — confirm scope); the domain-noun copy library contents (Mailable/Delivery/Suppression vocabulary in real sentences); whether the email logo slot is styled live text or PNG-placeholder path.
- **Phase 90 (quality gate):** Final grep denylist (planning language + SVG editor metadata + generic-phrase filler); file-size budgets; whether the runtime contrast matrix doubles as the scripted contrast check or the gate recomputes independently (research recommends both: rendered matrix + ~10-line script).

## Watch Out For

1. **(87, 90)** Live `<text>`/`font-family` in any shipped SVG — the v1.8 root failure. Outlined paths only; gate greps assets. (P-01)
2. **(87, 89)** Bare `currentColor` in file-based SVG assets resolves to black in GitHub/`<img>` contexts. Explicit hex fills; light/dark variant files. (P-02)
3. **(86, 88, 90)** Dark tokens defined but undemonstrated — the named v1.8 gap. The toggle must re-skin every specimen; Phase 90 audits the dark state explicitly. (P-11)
4. **(86)** Glass #277B96 used as link/body text on tinted surfaces (Mist/selected/info) — fails AA at 4.16–4.37. Route text-accent through `glass-deep`. Same trap on dark: Glass on Ink is 3.61.
5. **(88, 90)** `fetch()`/ES modules in index.html — works on a dev server, dies on `file://`. Inline everything; gate greps for `fetch(|type="module"`. (P-10)
6. **(85–90)** Planning-language leakage into shipped artifacts (phase names, "tournament", "codex", REQ-IDs, editor metadata) — the v1.8 tokens.json failure. Reader-facing from the first draft; denylist grep. (P-15)
7. **(87)** AI letterform tells: stem-width drift, missing overshoot, clotted joints, mixed roundness constants, decimal soup. Run the numeric self-audit (measure stems from `d` coordinates) before any option enters the tournament. (P-26)
8. **(87)** Detail that dies at 16px: interlocked ss, multi-stroke marks, stroke-interruption gaps < 0.35× stem width. Favicon is a redrawn ≤3-shape artifact, never a scaled lockup.
9. **(89)** Email specimen treated like web: SVG, flexbox, single dark-mode media query, pure black/white. Tables + inline styles + both metas; design the light version to survive Gmail's forced inversion. (P-17–P-19)
10. **(88, 89)** Pretending Inter renders: review once with Inter deactivated; no Inter-metric-dependent letter-spacing or pixel-tight alignment; typography section states the fallback honestly. (P-09)
