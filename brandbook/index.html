Mailglass brand system

Email, made visible.

A source-controlled brandbook for a Phoenix-native email framework that should feel clear, inspectable, calm, and technically credible.

The selected identity is the 07r no-i-dot 02 lockup: existing mark, tighter proximity, and one untouched full mailglass wordmark.

Identity Judgment

The logo direction is selected. Mailglass makes email visible. Mail you can see through. The mark supports that idea, while the full wordmark does the identity work.

Keep

Mailglass makes email visible. Calm, precise, Phoenix-native, maintainer-led.

Tighten

Use the selected tighter lockup and keep practical docs/header examples aligned.

Avoid

I-dot variants, word surgery, glassmorphism, paper planes, send arrows, mascots, and hype copy.

Token System

The source tokens are intentionally small. Use semantic roles in docs and marketing surfaces; do not copy raw hex into components unless creating the token file itself. Text, border, background, focus, and state roles are separate decisions.

--mg-bg: var(--mg-paper);
--mg-text: var(--mg-ink);
--mg-link: var(--mg-glass);
--mg-state-success: var(--mg-pine);
--mg-code-bg: #0a1521;
--mg-focus-ring: var(--mg-glass);

The implemented admin UI remains governed by mailglass_admin/docs/design-system.md. This brandbook is not a second admin UI framework; future product mapping should go through the existing Tailwind/daisyUI mechanics deliberately.

Files: tokens.json and tokens.css.

Logo System

Use the selected 07r no-i-dot 02 direction: mark plus one untouched full mailglass wordmark. The tighter gap makes the lockup read as one cohesive identity.

Primary lockup for README, docs, packages, and page headers.

Mark for compact brand surfaces and UI-adjacent use.

CurrentColor mark for mono, print, stamps, and single-color contexts.

Dark square avatar for social and profile surfaces.

Small browser/package mark; preserve the selected primitive.

Do not reintroduce i-dot variants, masks, dot cuts, dotless glyphs, split words, tspans, fake stems, or panes over the wordmark.
